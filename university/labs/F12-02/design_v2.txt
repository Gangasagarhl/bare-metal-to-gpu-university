# Design: serial console receive path (draft 2, after review)
Author: Ana. Reviewers: Kofi, Mei. Status: in review.

## Context
The kernel of OS302 prints to the serial port but cannot read from it yet.
We want a shell, so keyboard input over the serial line must reach a task.
The interrupt-driven UART code of F4-03 already raises one interrupt per received byte.

## Goals
G1: Every byte typed reaches the console task in the order it was typed.
G2: The interrupt handler never waits and never takes a lock.
G3: A paste longer than the ring loses only the bytes that do not fit, and counts them.
G4: The console task can wait for input with a deadline instead of spinning.

## Non-goals
Hardware flow control. A second UART. Line editing (the shell does that).

## Design
Single producer (the receive interrupt) and single consumer (the console task).
A ring of 8 slots with free-running head and tail counters: held = head - tail.
Full when held equals 8 slots; the new byte is then dropped and the drop counter grows.

## Interfaces
bool rx_pop(uint8_t& b): returns false at once when nothing is waiting.
bool rx_wait(std::chrono::microseconds deadline): false if no byte arrived in time.
std::size_t rx_dropped(): total bytes dropped since boot.
Ring size: 8 slots of 1 byte each.

## Alternatives considered
A1 Poll the UART from the console task: rejected, bytes are lost while the task sleeps.
A2 Overwrite the oldest byte when full: rejected, it loses the start of a command.
A3 A larger ring: kept as an option; the drop counter tells us whether it is needed.

## Failure modes
Ring full: drop the new byte, increase the drop counter (G3).
Deadline of 0 us: rx_wait returns at once, like rx_pop.
Counters reach their largest value: unsigned wrap keeps head - tail correct.

## Test plan
T1 (G1): host test pushes "abcdefghij" in two halves and pops them in order.
T2 (G2): code review of the handler: no loop, no lock, no call that can sleep.
T3 (G3): host test pushes 9 bytes: 8 held, 1 dropped, rx_dropped() returns 1.
T4 (G4): QEMU test with no input: rx_wait(5000 us) returns false within the deadline.
