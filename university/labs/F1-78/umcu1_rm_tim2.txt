7.3  Clock tree (summary; full text in F1-75)
     TIM2 is clocked by TIM2CLK. TIM2CLK = PCLK1 if the APB1 prescaler is 1,
     otherwise TIM2CLK = 2 x PCLK1. In the lab configuration TIM2CLK = 72 MHz.

7.6  RCC_APB1ENR - APB1 peripheral clock enable register     address 0x4002 101C
     Bit 0  TIM2EN (rw)  1 = TIM2 clock enabled. Reset value 0.
     While TIM2EN = 0, writes to TIM2 registers are ignored and reads return 0x0000.

14   General-purpose timer TIM2                                  base address 0x4000 0000

14.1 Overview
     16-bit up-counter with a 16-bit prescaler and one capture/compare channel (CH1).
     The counter counts from 0 up to TIM2_ARR, then restarts from 0. At this restart
     the timer generates an UPDATE EVENT (UEV) and sets the UIF flag.

14.2 Counter clock
     CK_CNT = TIM2CLK / (PSC + 1).
     TIM2_PSC is BUFFERED: a value written to TIM2_PSC is copied into the active
     prescaler only at the next update event. Software can force an update event
     with TIM2_EGR.UG (see 14.4.5); this also clears the counter.
     TIM2_ARR is buffered only when TIM2_CR1.ARPE = 1; with ARPE = 0 a new ARR value
     is used immediately.

14.3 PWM mode 1 (channel 1)
     When TIM2_CCMR1.OC1M = 110 and TIM2_CCER.CC1E = 1, output OC1 is high while
     CNT < TIM2_CCR1 and low otherwise.
     PWM frequency = CK_CNT / (ARR + 1).   Duty cycle = CCR1 / (ARR + 1).

14.4 Register map (offsets from the TIM2 base address; all registers 16 bits wide,
     accessed as 32-bit words; reserved bits must be written as 0)

     Offset Name        Reset   Bits
     0x00   TIM2_CR1    0x0000  bit 7 ARPE (rw)  auto-reload preload enable
                                bit 0 CEN  (rw)  counter enable
     0x0C   TIM2_DIER   0x0000  bit 0 UIE  (rw)  update interrupt enable
     0x10   TIM2_SR     0x0000  bit 0 UIF  (w1c) update interrupt flag
     0x14   TIM2_EGR    0x0000  bit 0 UG   (w)   update generation
     0x18   TIM2_CCMR1  0x0000  bits 6:4 OC1M (rw) output compare 1 mode
     0x20   TIM2_CCER   0x0000  bit 0 CC1E (rw)  channel 1 output enable
     0x24   TIM2_CNT    0x0000  bits 15:0 (rw)   counter value
     0x28   TIM2_PSC    0x0000  bits 15:0 (rw)   prescaler (buffered, 14.2)
     0x2C   TIM2_ARR    0xFFFF  bits 15:0 (rw)   auto-reload value
     0x34   TIM2_CCR1   0x0000  bits 15:0 (rw)   capture/compare value 1

14.4.4 TIM2_SR.UIF (w1c)
     Set by hardware at every update event. Software clears it by WRITING 1 to it.
     Writing 0 has no effect.

14.4.5 TIM2_EGR.UG (w)
     Writing 1 generates an update event: the counter restarts from 0 and the buffered
     PSC (and ARR when ARPE = 1) values become active. UIF is set by this event as well.
     Always reads 0.

14.5 Configuration sequence (recommended)
     1. Set RCC_APB1ENR.TIM2EN = 1.
     2. Write PSC, ARR (and CCR1, CCMR1, CCER for PWM).
     3. Write TIM2_EGR.UG = 1 so that PSC is loaded now, then clear UIF (write 1).
     4. Set TIM2_CR1.CEN = 1.
