MA101 practical exam (P) - lab folder

Candidates receive ONLY the starting files the paper names (owner ruling B7):
  helpers_exam_start.cpp   the program to complete (three marked TODO lines)
  helpers_exam_start.in    the exam input: jobs and team size (300 32)
  plan_bug.out             evidence for Part C (output of a broken plan program)
Nothing else in this folder is given to candidates.

Reference solution and hidden evidence (Lab Engineer; for markers only):
  helpers_exam.cpp / .in   the completed program, run with the exam input
  run.sh                   runs the reference solution on two more inputs
                           (helpers_case2: 320 32, helpers_case3: 321 32)
  plan_bug.cpp / .in       the deliberately broken program behind Part C
  teams_bug.cpp            the deliberately broken program behind the final
                           exam's forensic question
  exam_checks.cpp          recomputes every number in the MA101 answer keys

Every .out and .log file is written by university/labs/run_lab.sh.
