C. Fact list

  • F1 A microcontroller datasheet describes one chip with a CPU, on-chip flash and RAM, timers, an ADC and input/output pins. Source: D5 Features, Description. Used in: Jargon (Microcontroller); Layer 1.
  • F2 The datasheet gives input threshold voltages, a current limit per output pin and for all outputs together, and a tolerance for the built-in clock. Source: D5 port tables, DCO table. Used in: Jargon (High and low); hardware; Breaks 2.
  • F3 setup runs once when the board is powered or reset; loop runs over and over again forever; pinMode OUTPUT; digitalWrite HIGH/LOW. Source: D6 Blink. Used in: Jargon (Pin, Program loop, Firmware); Layers 1–2; Breaks 1; Figure 1.
  • F4 delay() pauses for a time given in milliseconds; no other sensor reading or pin change can go on during it. Source: D6 delay(). Used in: Jargon (Millisecond); Layer 3; Breaks 3.
  • F5 An output pin is low-impedance and can source or sink only a limited current. Source: D6 OUTPUT. Used in: hardware.
  • F6 The reference kit names the BBC micro:bit V2 (on-board LEDs). Source: K1. Used in: Code note; D3.
  • F7 Simulated blink times 0/500/1000… ms, total 3000 ms; broken blink never turns off. Source: R1. Used in: Worked example; forensic.
