C. Fact list

One entry per tagged claim in the chapter (the claim text as it stands after the verification pass, the tag that supports it, and the chapter section). Every document section named in a tag was opened and the fact was found there; R-ids are this build's lab runs.

  1. F1 Simple words: A list of exact steps that a computer follows. Analogy: A recipe that the cook follows word for word. Precise: A set of instructions for a computer; in this course it starts as C++ source code and is turned by a compiler into an executable that the operating system can run. source: R1, D2 §3.2; used in: F0-29-jargon
  2. F2 Simple words: The text of a program, written by a person in a programming language. Analogy: The recipe written in your own handwriting on a card. Precise: The human-readable text of a program, stored in files such as hello.cpp; the compiler reads it and either reports errors or produces an executable. source: R1, D2 §3.2; used in: F0-29-jargon
  3. F3 … turns the text you wrote into a program the computer can run. Analogy: A helper who rewrites your recipe in the only language the cook can read, and refuses if the recipe makes no sense. Precise: A program (here g++) that checks C++ source code against the rules of the language and translates it into machine instructions stored in an executable file; it reports errors and warnings when it cannot. source: R4, D2 §3.2, §3.8; used in: F0-29-jargon
  4. F4 Simple words: The finished program file that the computer can start. Analogy: The recipe after it was rewritten for the cook: ready to use, but no longer easy for you to read. Precise: A file of machine instructions and data produced by the compiler; on the Linux build machine of this course the file tool describes it as an ELF 64-bit executable, and its first bytes are 7f 45 4c 46. source: R4, D5 e_ident; used in: F0-29-jargon
  5. F5 Simple words: The set of programs you use to turn source code into a running program. Analogy: Your kitchen tools: the same recipe needs the right pots and an oven. Precise: The compiler and the programs that work with it (and, in F0-37, the debugger). This course records the exact versions the tools print, for example "g++ (Ubuntu 13.3.0-6ubuntu2~24.04.1) 13.3.0". source: R4, D2 §3.2; used in: F0-29-jargon
  6. F6 Simple words: The place where every C++ program starts. Analogy: The first line of the recipe: "start here". Precise: The function named main, which the program runs first; the value it returns (0 here) becomes the exit code that the run log records. source: R1, D4 §6.9.3.1, §17.5; used in: F0-29-jargon
  7. F7 Simple words: One instruction in a program. In C++ most statements end with a semicolon. Analogy: One step of the recipe. Precise: A single instruction inside a function body, such as std::cout << "Hello"; statements run one after another, from top to bottom, unless a statement such as if or a loop changes the order. source: R2, D4 §8.3, §6.9.1; used in: F0-29-jargon
  8. F8 Simple words: The name C++ uses for "print this on the screen". Analogy: The cook calling out loud what is happening. Precise: The standard output stream from the header <iostream>; the operator << sends text and numbers to it, and the run log captures what it printed. source: R1, D4 §29.4.3; used in: F0-29-jargon
  9. F9 Simple words: Text written inside double quotes in your program. Analogy: Words copied exactly onto a label. Precise: A sequence of characters between double quotes in source code, such as "Hello, world!\n"; the program uses it exactly as written. source: R1, D4 §5.13.5; used in: F0-29-jargon
  10. F10 Simple words: The invisible character that says "start a new line here". Analogy: Pressing the Enter key on a typewriter or keyboard. Precise: The character written '\n' in C++; without it, the next output continues on the same line (R3 shows two messages glued together). source: R3, D4 §5.13.3; used in: F0-29-jargon
  11. F11 A C++ program is one or more text files whose names end in .cpp. Our first one is hello.cpp. It contains a main function: the place where the program starts. Inside main there are statements. Each of these statements is one instruction and ends with a semicolon. source: R1, D4 §6.9.3.1, §8.3; used in: F0-29-layer2
  12. F12 To print, the program sends text to std::cout with the << sign. The text is a string literal: characters between double quotes. The two characters \n inside it mean "start a new line". They are one invisible character, the newline. source: R1, R3, D4 §5.13.3, §5.13.5; used in: F0-29-layer2
  13. F13 That is long, so here is what each part does. -std=c++20 picks the version of the C++ rules. -Wall -Wextra -Wpedantic turn on many warnings. -Werror turns every warning into an error, so nothing suspicious slips through. -g keeps information for the debugger (F0-37). -fsanitize=address,undefined adds extra checks while the program runs. -o hello names the output file. source: R4, D2 §3.2, §3.4, §3.8, §3.10, §3.12; used in: F0-29-layer2
  14. F14 … iling" is really several jobs in a row. g++ first prepares the text (it pulls in the contents of headers such as <iostream>), then translates C++ into machine instructions (the GCC manual counts this as two jobs, compiling and assembling), and finally joins your code with ready-made library code into one executable. That last job is called linking. You will study each job in SP101 (chapter F2-01). source: D2 §3.2; used in: F0-29-layer3
  15. F15 … instructions: numbers that stand for tiny steps such as "add" or "copy". That is why the compiler is needed. The executable is a long list of such numbers, plus the text "Hello, world!" stored as bytes. When you run it, the operating system loads the file into memory, and the processor follows the instructions one by one. You met the processor and memory as the kitchen's cook and pantry in F0-05. source: R4, D6, D7 §1.1; used in: F0-29-hardware
  16. F16 Tomás, the helper, would fix a small spelling mistake himself. The compiler never guesses what you meant. It stops and reports, and you fix it. (It may suggest a fix, as F0-36 shows, but it does not apply it.) source: R4, D2 §3.7; used in: F0-29-breaks
