C. Fact list

One entry per tagged claim in the chapter (the claim text as it stands after the verification pass, the tag that supports it, and the chapter section). Every document section named in a tag was opened and the fact was found there; R-ids are this build's lab runs.

  1. F1 Simple words: The kind of value a variable can hold: whole number, decimal, true/false, letter or text. Analogy: The shape of a jar: an egg box holds eggs, a bottle holds liquids. Precise: The property of a variable or value that decides which values it can hold and which operations work on it, for example int, double, bool, char and std::string. source: R1, D3 §6.8.1; used in: F0-31-jargon
  2. F2 Simple words: The type for whole numbers, like 7 or -3. Analogy: A jar for whole eggs: no half eggs allowed. Precise: The basic signed integer type; on the build machine it used 4 bytes and its largest value printed as 2147483647 (R3). source: R1, R3, D3 §6.8.1; used in: F0-31-jargon
  3. F3 Simple words: The type for numbers with a decimal point, like 1.5. Analogy: A measuring jug that can hold 1.5 litres. Precise: A floating-point type; many decimals, such as 0.1, are stored only approximately, which is why 0.1 + 0.2 printed as 0.30000000000000004 with 17 digits (R2). source: R1, R2, D3 §6.8.1; used in: F0-31-jargon
  4. F4 Simple words: The type for yes/no answers: true or false. Analogy: A light switch: on or off. Precise: The Boolean type with the two values true and false; std::cout prints them as 1 and 0 unless std::boolalpha is used (R1). source: R1, D3 §6.8.1, §29.5.6.1; used in: F0-31-jargon
  5. F5 Simple words: The type for one single character, like 'A'. Analogy: One fridge-magnet letter. Precise: A type that holds one character, written in single quotes; the character 'A' printed as the number 65 when converted to int on the build machine (R1). source: R1, D3 §6.8.1; used in: F0-31-jargon
  6. F6 Simple words: The type for a piece of text, like a name or a sentence. Analogy: A string of fridge-magnet letters in a row. Precise: The standard library type from <string> that holds a sequence of characters; it can be joined with + and knows its length through size() (R1, R4). source: R1, R4, D3 §21.3.3.1, §21.3.2.4; used in: F0-31-jargon
  7. F7 Simple words: Dividing whole numbers in C++ gives a whole number: the part after the point is dropped. Analogy: Sharing 7 eggs between 2 boxes: each box gets 3 whole eggs, and 1 egg is left over. Precise: When both operands of / are integers, the result is an integer and the fractional part is discarded: 7 / 2 printed 3 and 7 % 2 printed the remainder 1 (R2). source: R2, R5, D3 §7.6.5; used in: F0-31-jargon
  8. F8 Simple words: The % sign: it gives what is left over after a whole-number division. Analogy: The egg that does not fit in the boxes. Precise: The operator % on integers; 7 % 2 printed 1 in this build (R2). source: R2, D3 §7.6.5; used in: F0-31-jargon
  9. F9 An int holds whole numbers, positive or negative. A double holds numbers with a fractional part, such as 1.5. A bool holds true or false. A char holds one character, written in single quotes: 'A'. A std::string holds text in double quotes; you need #include <string> for it. source: R1, D3 §6.8.1; used in: F0-31-layer2
  10. F10 When both numbers in a division are int, the result is an int too. The part after the decimal point is thrown away. So 7 / 2 printed 3. The remainder operator % gives the leftover: 7 % 2 printed 1. If at least one number is a double, the division keeps the fraction: 7.0 / 2 printed 3.5. source: R2, D3 §7.6.5; used in: F0-31-layer2
  11. F11 Printing true showed 1. After std::boolalpha was sent to std::cout, the same value printed as true. Printing the char 'A' showed the letter, but converting it to int with static_cast<int> showed 65. A character is stored as a number code, the idea you met in F0-03. source: R1, D3 §29.5.6.1, §6.8.1; used in: F0-31-layer2
  12. F12 Strings can be joined with + when at least one side is a std::string: "Hello, " + name + "!" works because name is a std::string. The function size() counts the characters: "soup" has 4. source: R1, R4, D3 §21.3.3.1, §21.3.2.4; used in: F0-31-layer2
  13. F13 A double cannot store most decimals exactly. The C++ rules leave the exact way a double is stored to each machine, and on the build machine 0.1 + 0.2 printed as 0.3 with the normal number of digits, but as 0.30000000000000004 when 17 digits were requested. So never test whether two double values are exactly equal; you will learn the safe way in later courses (MA302). source: R2, D3 §6.8.1; used in: F0-31-layer3
  14. F14 Other computers may differ. This build measured the sizes of int and double on one machine only. The C++ rules allow other sizes: they promise only that an int has at least 16 bits, that a double is at least as precise as a float, and they leave the rest to each kind of computer (the rules call this "implementation-defined"). So treat Listing 3's numbers as "measured on this machine". source: R3, D3 §6.8.1; used in: F0-31-layer3
  15. F15 Memory stores only bits: rows of switches, as in F0-02. The type tells the program how to read a row of bits. The same bits could mean a number, a letter or true/false; the type decides which. That is why the letter 'A' could be printed as the number 65: same bits, different reading. Whole numbers and decimal numbers are stored in quite different bit patterns, which is one reason C++ keeps their types apart. source: R1, D3 §6.7.1, §6.8.1; used in: F0-31-hardware

D. Not found / conflicting

  • N1 "A double stores numbers in binary": the C++ working draft says only that the representation of floating-point types is implementation-defined (D3 §6.8.1); the representation on the build machine was not found in an opened source. The chapter sentence was reworded to "the C++ rules leave the exact way a double is stored to each machine" plus the measured output (R2).
  • N2 The texts of "A Tour of C++" (Third edition) chapter 1 and of Petzold's "Code" (2nd Edition) were not opened (only the author's/publisher's pages, the table of contents and, for the Tour, the free sample chapter 12); no claim rests on them alone, and they are listed in the chapter as further reading.
