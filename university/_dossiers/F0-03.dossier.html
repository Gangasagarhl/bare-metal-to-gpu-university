Notes per document (paraphrased): what each document was used for is given in the chapter's Sources list, in the same words as "Used for".

  • D1: the meaning of a collection of bits is always understood from context.
  • D2: char, std::string, static_cast and reading with std::cin; the standard requires the digits 0 to 9 to have consecutive numbers, and states no such rule for letters.
  • D3: ASCII as a United States standard 7-bit code; the numbers of SP (32), "!" (33), "0" (48), "2" (50), "A" (65), "H" (72), "L" (76), "Z" (90), "a" (97), "i" (105), "~" (126); control characters in the first two columns (0 to 31) and DEL (127).
  • D4: ASCII as 128 characters (U+0000 to U+007F); Unicode code points run from 0 to 10FFFF in hexadecimal (1,114,111 in decimal).
  • D5: an image as a rectangular array of pixels; a truecolour pixel as three samples: red, green and blue; 8-bit samples.
  • D6: digital audio as samples taken at a fixed sample rate (sample-frames per second); audio sent to the final destination, usually the audio hardware.
  • D7: text stored as ASCII bytes; the same bits mean different things in different contexts.
  • D8: in the book's computer, a pressed key's code appears in a memory location (the keyboard memory map), and the screen shows what is written in its own memory map of pixels.
