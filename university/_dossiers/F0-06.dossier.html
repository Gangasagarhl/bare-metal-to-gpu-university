  • D1: input and output devices (keyboard and mouse for input, display for output, disk); devices connected to the processor and memory through buses.
  • D2: memory-mapped input and output: the memory map reflects an input device's state, and an output device reflects its memory map; a program that reads two input values and writes a result (Max.hack).

  • D5: in the book's computer, a pressed key's code appears in the keyboard's memory map.
  • D6: a light sensor that measures the intensity of visible light and reports a digital result; its measurement range is given in the datasheet.
