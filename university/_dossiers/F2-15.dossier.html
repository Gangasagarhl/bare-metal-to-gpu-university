C. Not found / not opened

  • A tier 1–3 statement that "caches fetch memory in blocks" was not found in an openable document (Arm developer documentation returned HTTP 403). The chapter now uses the wording of D3 SL.con.2 ("cache-friendly", "prefetcher-friendly") and D1 12.9 instead.
  • Whether violating the strict weak ordering is formally "undefined behaviour": the opened text of 25.8 says only that comp "shall" induce one; the chapter now says the standard no longer promises anything about the result.
