B. Facts (keyed to the chapter's claim tags)

FactStatement as used in the chapter (shortened)Source tag(s)Used in
F1Precise: a pin whose direction, output level and input sampling are controlled by software through the GPIO peripheral's registers (direction or mode, output data, input data, and often pull-up/pull-down and output-type settings).D6 §3.1.3, §9.6; D10 GPIO_TypeDefable
F2Precise: a push-pull output has transistors to both supply and ground and drives either level; an open-drain output has only the transistor to ground, so the high level must come from a pull-up resistor, which lets several outputs share one wire (as I2C does).D11 §4.6.20 Figure 43, §4.5; D6 §12.2able
F3Precise: a resistor (internal, enabled by a GPIO register, or external on the board) from an input to the supply or to ground, so that the input reads a known value when nothing drives it.D6 §9.6able
F4Precise: a peripheral with a counter register clocked by a (prescaled) peripheral clock, a reload or compare value that defines its period, a status flag set at each period, and usually an interrupt request and compare/capture channels.D7 §4.2; D6 §12.5.1able
F5Precise: the register whose value defines the counter's period; for a counter running 0…N or N…0 the period is N + 1 counter clocks.D6 §12.5.2.6able
F6Precise: a periodic digital signal whose period is fixed and whose high time (pulse width) encodes a value; the ratio of high time to period is the duty cycle.D6 §12.5.1, §12.5.2.1able
F7Precise: a register compared with the counter on every count; the comparison drives an output pin in PWM modes or raises an event flag.D6 §12.5.2.1; D10 TIM_TypeDef (CCR1–CCR4), TIM_SR_CC1IFable

F22The CMSDK APB timer has CTRL at 0x000 (bit 0 enable, bit 3 interrupt enable), VALUE at 0x004, RELOAD at 0x008 (a write also sets the current value) and INTSTATUS/INTCLEAR at 0x00C ("Write one to clear").D7 §4.2.1 Table 4-4l3-modes
F23On the AN385 board, Timer0 is at 0x40000000, and the FPGA I/O block's LED register FPGAIO->LED0 is at 0x40028000 with the LEDs in bits [1:0]; the board's SYSCLK is 25 MHz.D8 §3.7 Table 3-4, §3.15, §4l3-modes
