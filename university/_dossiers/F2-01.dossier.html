C. Facts (keyed to the chapter's claim tags)

  1. F1 [D3 §3.2] GCC compiles in up to four stages, "preprocessing, compilation proper, assembly and linking, always in that order"; -E stops after preprocessing, -S after compilation proper, -c compiles or assembles without linking (output: one object file per source file). Used in: jargon (Build, Preprocessor, Assembly code, Object file), figure caption, layer2, breaks, answers.
  2. F2 [D2 §5.1] A source file together with everything it includes, less lines skipped by conditional inclusion, is a translation unit; translation units can be separately translated and later linked. Used in: jargon (Translation unit), layer2.
  3. F3 [D2 §5.2] C++20 has nine phases of translation: 1–4 preprocessing (phase 4: "Preprocessing directives are executed", #include processed recursively), 7 tokens analysed and translated, 8 required template instantiations, 9 "All external entity references are resolved. Library components are linked"; footnote: implementations behave as if the phases occur, but may fold them. Used in: jargon (Preprocessor), layer3 (correction: the earlier text said eight phases with linking in phase 8, which is the numbering of a later draft).
  4. F4 [D2 §15.3] An #include directive is replaced by "the entire contents" of the named header or source file. Used in: jargon (Preprocessor), breaks.
  5. F5 [D2 §6.2] A function declaration without a body is a declaration that is not a definition. Used in: layer2.
  6. F6 [D3 §3.19.54] For x86, -masm=dialect chooses att or intel; "The default is att". Used in: jargon (Assembly code).
  7. F7 [D9] ELF type ET_REL is "A relocatable file"; an object file's symbol table locates and relocates symbolic definitions and references; "Relocation is the process of connecting symbolic references with symbolic definitions"; relocatable files carry relocation entries. Used in: jargon (Object file, Symbol), layer3.
  8. F8 [D6 §2] nm: type T = "in the text (code) section", U = "undefined"; -C demangles C++ names. Used in: jargon (Symbol, Name mangling), layer2, answers.
  9. F9 [D8 §1] "ld combines a number of object and archive files, relocates their data and ties up symbol references." Used in: jargon (Linker), transition.
  10. F10 [D10 (Linking)] The linker's symbol resolution "associates each symbol reference with exactly one symbol definition"; relocation moves code to final locations and "updates all references"; an executable object file "can be copied directly into memory and then executed". Used in: jargon (Linker), layer2, layer3, hardware.
  11. F11 [D3 §3.3] g++ "automatically specifies linking against the C++ library". Used in: layer2.
  12. F12 [D7 §5.1.2, §5.1.5.2] Mangled names start with _Z; a source name is a length followed by the identifier; builtin type i = int; GCC follows this ABI (D3 §9). Used in: jargon (Name mangling), layer2, breaks.
  13. F13 [D3 §3.15] -nostartfiles: "Do not use the standard system startup files when linking", so by default they are linked in. Used in: layer3, forensic key.
  14. F14 [D10 (Machine-Level Programming I)] Conditional jumps use the condition codes set by cmp/test ("Conditional Goto"). Used in: hardware.
  15. F15 [R1–R6] All quoted outputs, line counts (12 and 43,178), symbol lines, assembly lines and error messages are copied from the recorded runs. Used in: throughout.
