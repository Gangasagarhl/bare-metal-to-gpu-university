Fact list (keyed to the chapter's claim tags)

  1. F1 (jargon) an integrated circuit made of an array of configurable logic blocks, programmable interconnect and I/O blocks, whose function is set by loading configuration data. — source: D5 “FPGAs: Field Programmable Gate Arrays”, “General FPGA Layout”; D6 ch. 1
  2. F2 (jargon) a k-input LUT is a 2 k -bit memory addressed by its k inputs; its contents are configuration bits, so it implements any Boolean function of k inputs. — source: D7 “Look-Up Table”; D5 “LE: Logic Element”
  3. F3 (jargon) the basic logic tile of an FPGA, usually grouping LUTs, flip-flops, multiplexers and carry logic; names and contents differ by vendor. — source: D7 “CLB Overview”; D5 “LE: Logic Element”
  4. F4 (jargon) routing channels and switch boxes whose connections are set by configuration bits. — source: D5 “FPGAs: Field Programmable Gate Arrays”; D6 ch. 1
  5. F5 (jargon) the configuration data, produced by the vendor toolchain, that sets every LUT, flip-flop option and routing switch of a specific device. — source: D6 ch. 1
  6. F6 (jargon) the tool steps that assign netlist cells to physical sites on the device and choose routing resources, followed by timing analysis. — source: D5 “FPGA Design Flow”; D11 §2
  7. F7 (jargon) dedicated SRAM blocks in the FPGA fabric, usually with synchronous (clocked) read ports. — source: D8 RAMB18E1
  8. F8 (fig1) Real devices group several LUTs per block, add carry chains and other dedicated blocks, and differ by vendor — source: D7 “CLB Overview”; D5 “General FPGA Layout”
  9. F9 (fig2) Change the 16 bits and the same hardware computes a different function; Listing 1 checks four such configurations — source: D7 “Look-Up Table”; R1
  10. F10 (layer2) If you store the 16 output bits in a 16-bit memory and use the 4 inputs as the address, reading the memory is evaluating the function — source: D5 “Logic with Memory Arrays”
  11. F11 (layer2) Logic blocks, routing and the rest A LUT followed by a flip-flop can be one bit of any synchronous design: the LUT computes the next-state logic for that bit, the flip-flop stores it — source: D5 “LE: Logic Element”; D7 “CLB Overview”
  12. F12 (layer2) An FPGA repeats this tile many times and adds programmable routing between tiles, I/O blocks for the pins, block RAMs for memories ( F1-20 ), and usually dedicated arithmetic and clock-distribution resources ( F1-18 ) — source: D5 “FPGAs: Field Programmable Gate Arrays”; D7 “CLB Overview”; D10 §2.2.3
  13. F13 (layer2) Synthesise: turn it into a netlist of LUTs and flip-flops — source: D2 synth
  14. F14 (layer2) Place and route onto a specific device, then check timing: does every path fit within the clock period you constrained — source: D5 “FPGA Design Flow”; D11 §2
  15. F15 (layer2) Generate the bitstream and load it into the device through one of its configuration interfaces; the JTAG interface, for example, is always available on one vendor's device family — source: D6 ch. 1
  16. F16 (layer3) There is no manufacturing step: a new design is a new bitstream, loaded into the configuration memory of the same chip — source: D6 ch. 1
  17. F17 (hardware) …e vendor's family, the configuration is held in volatile memory inside the chip, so it is lost when the power goes off, and the device loads its bitstream again after power-up, for example from an external non-volatile memory chip — source: D6 ch. 1
  18. F18 (hardware) Other families keep their configuration in on-chip flash memory, which keeps it without power — source: D9
  19. F19 (hardware) …e flip-flops through dedicated global, low-skew clock routing, so that the clock edge reaches every flip-flop at nearly the same time ( F1-18 ); FPGA design guides recommend PLL outputs as the source of internally generated clocks — source: D10 §2.2.3
  20. F20 (breaks) A LUT computes one function of at most k inputs — source: D7 “Look-Up Table”
  21. F21 (breaks) A new circuit is a new bitstream loaded into the chip's configuration memory — source: D6 ch. 1
  22. F22 (breaks) Routes through programmable interconnect add delay to a path, and the timing analysis after place and route checks every path against the clock period, as in F1-18 — source: D11 §2
  23. F23 (transition) What carries over: the same HDL, the same simulation-first habit, and the same synthesis report; a LUT is the memory of F1-20 read through the multiplexer of F1-12 — source: D5 “Logic with Memory Arrays”
