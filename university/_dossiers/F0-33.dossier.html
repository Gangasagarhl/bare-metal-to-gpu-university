C. Fact list

One entry per tagged claim in the chapter (the claim text as it stands after the verification pass, the tag that supports it, and the chapter section). Every document section named in a tag was opened and the fact was found there; R-ids are this build's lab runs.

  1. F1 Simple words: A part of a program that repeats. Analogy: "Stir 20 times." Precise: A statement (while, for) that runs its block again and again as long as its condition is true. source: R1, D3 §8.6.1, §8.6.3; used in: F0-33-jargon
  2. F2 Simple words: A loop that checks its condition before every round, and stops when it is false. Analogy: "While the timer is above zero, wait one more second." Precise: while (condition) { ... } evaluates the condition before each iteration and runs the block only while it is true (R2). source: R2, D3 §8.6.1; used in: F0-33-jargon
  3. F3 Simple words: A loop with a counter built in: start, keep going while, and step. Analogy: Counting your stirs out loud: "one, two, three…" up to five. Precise: for (start; condition; step) { ... } runs start once, then checks the condition before each iteration and runs step after each one (R1). source: R1, D3 §8.6.3; used in: F0-33-jargon
  4. F4 Simple words: One round of a loop. Analogy: One stir of the spoon. Precise: A single execution of a loop's block. source: R1, D3 §8.6.1; used in: F0-33-jargon
  5. F5 Simple words: A variable that counts how many times something happened. Analogy: Counting stirs on your fingers. Precise: A variable, usually an int, that is increased (for example with ++day) on each iteration and often used in the loop's condition. source: R1, D3 §7.6.2.2; used in: F0-33-jargon
  6. F6 Figure 1. The path through the for loop of Listing 1. Start runs once; then condition, block and step repeat until the condition is false. The arrows show the order of execution. The real run printed stirs 1 to 5, then "Finished stirring." source: R1, D3 §8.6.3; used in: F0-33-pictures
  7. F7 A while loop has the form while (condition) { block }. The condition is checked before every iteration. If it is true, the block runs, and then the condition is checked again. In Listing 2, seconds starts at 5 and the block subtracts 1 each time; when it reaches 0, seconds > 0 is false, and the loop ends after 5 iterations. source: R2, D3 §8.6.1; used in: F0-33-layer2
  8. F8 A for loop packs the three loop parts into one line: for (start; condition; step). The start runs once. Then, as long as the condition is true, the block runs and then the step runs. Listing 1 uses int stir = 1, stir <= 5 and stir = stir + 1. source: R1, D3 §8.6.3; used in: F0-33-layer2
  9. F9 Programmers usually write the step stir = stir + 1 more shortly as ++stir; Listing 3 uses that form with ++day. Both add 1 to the counter. source: R3, D3 §7.6.2.2; used in: F0-33-layer2
  10. F10 For the curious. Choosing between while and for is about clarity, not power: any for loop can be rewritten as a while loop with the start before it and the step at the end of its block. Use for when you know how many times to repeat, and while when you repeat until something happens, such as "until the player guesses right" in F0-38. source: D3 §8.6.3; used in: F0-33-layer3
  11. F11 The forensic program uses std::endl instead of '\n'. std::endl also pushes the text out at once. That matters here: the runner stops the program from outside, and text still waiting inside the program would be lost (F0-35 shows this happening). source: D3 §29.7.5.4; used in: F0-33-layer3
  12. F12 … top. (The RISC-V processor family, for example, has jump instructions and branch instructions that compare two values and jump only if the test holds.) When the compare says "false", a jump forwards skips past the loop. The processor has no idea it is "in a loop"; it follows jumps. That is also why it never gets bored or tired, and why it will happily run an infinite loop until something stops it. source: R4, D4 §1.1.5; used in: F0-33-hardware
  13. F13 A cook gets tired and slows down. The processor repeats the thousandth iteration exactly like the first; it never gets tired and never gets bored. source: R4, D4 §1.1.5; used in: F0-33-breaks
  14. F14 "Stir 20 times" counts from 1 in a kitchen. Programmers often count from 0 (for (int i = 0; i < 20; ++i) also runs 20 times), which you will need for lists in F0-35. source: D3 §8.6.3; used in: F0-33-breaks
