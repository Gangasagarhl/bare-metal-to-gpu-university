C. Facts (keyed to the chapter's claim tags)

  1. F1 [D4 §2.4] SWMR invariant: for any memory location, at any moment, either a single core may write it (and read it) or some number of cores may only read it; data-value invariant: the value at the start of an epoch equals the value at the end of the last read-write epoch; coherence is usually maintained at cache-block granularity (§2.4.2). Used in: jargon (coherence), layer 1, l2-problem, transition.
  2. F2 [D4 §6.4.1] MOESI stable states: M "valid, exclusive, owned, and potentially dirty" (may be read or written); O "valid, owned, and potentially dirty, but not exclusive"; E "valid, exclusive, and clean" (treated as an ownership state); S "valid but not exclusive, not dirty, and not owned"; I invalid. Used in: jargon (MESI), l2-mesi, layer 3 (variants, atomics), breaks 1.
  3. F3 [D4 §6.4.2] Transactions: GetS obtains a block in Shared; GetM obtains it in Modified; Upg upgrades a read-only block to Modified without data being sent; PutS/PutE/PutO/PutM evict (some protocols make PutS or PutE silent). Used in: l2-trans.
  4. F4 [D4 §6.4.3] Snooping: the requestor broadcasts to all coherence controllers and the interconnect must deliver requests in a consistent order; "logically simple" but does not scale well. Directory: unicast to the home, which tracks owners and sharers; scales better but can add a hop. Invalidate protocols remove other copies before a write; update protocols push the new value but cost bandwidth. Used in: jargon (snooping, directory, invalidation), l2-snoop, hardware.
  5. F5 [D4 §8.1, §8.2.2, §8.5, §8.6] Directory entries hold state, owner and a sharer list; directories achieve "greater scalability (i.e., because it requires less bandwidth)"; "This additional level of indirection increases the latency of some coherence transactions"; the full sharer set "requires a significant amount of storage" (coarse vectors, limited pointers); directory caches, inclusive directory caches with duplicate L1 tags, null directory caches. Used in: l2-snoop, hardware, answers 7.
  6. F6 [D4 §1.1–1.2, §3.3] Consistency (ordering of accesses to different locations) is distinct from coherence (per location). Used in: layer 3 (coherence is not consistency), breaks 3.
  7. F7 [D11 §11.6] Private per-core caches with a shared lower level; a coherence protocol lets a core see the most recently modified value; MSI: a read in I makes an M holder write back and drop to S; a write in I or S makes other S copies I and an M holder write back and go to I; snooping on a shared bus is common; directory-based schemes scale better but are slower; MSI, MESI and MOESI are write-invalidate protocols. Used in: jargon (coherence, MESI, snooping), layer 1, l2-trans, l2-snoop, Figure 1 caption.
  8. F8 [D11 §14.5] A write invalidates the whole cache line, not just the changed element; false sharing is the illusion that elements are shared when they are not; a 10-entry (40-byte) counts array fits in one 64-byte line; timings 0.336 s (1 thread), 0.799 s (2), 0.767 s (4); fixes: padding (wastes memory, machine-dependent) or per-thread local counts merged once under a mutex. Used in: jargon (false sharing), layer 1, l2-false, Figure 2 caption.
  9. F9 [D6 6.8.3] Alignment is "the number of bytes between successive addresses" at which an object can be allocated; extended alignment > alignof(std::max_align_t); such a type is over-aligned. Used in: l2-false (alignas(64)).
  10. F10 [D4 ch. 7 §7.3 (title) / D3 ch. 5 (title)] The E state's motivation (read-then-write of a private block in one transaction), Forward state, duplicate tags for snoop lookups: chapter 7 text and D3 not openable; cited at chapter or section-title level. Used in: l2-trans (E motivation), layer 3 (variants), hardware.
  11. F11 [R1–R4] mesi.in: states as in the worked example, 7 bus transactions; pingpong one transaction per write, padded two in total; false_sharing packed 125.8 / 1109.4 / 2489.6 ms vs padded 124.0 / 121.5 / 283.7 ms for 1/2/4 threads; TSan build: no report. Used in: worked example, code walk-through, forensic lab and key.
