C. Facts (keyed to the chapter's claim tags)

  1. F1 [D3 ch. 26] A thread is a single point of execution with its own program counter, private registers and its own stack; threads of one process share the address space. Used in: jargon "Thread".
  2. F2 [D3 ch. 26] The shared-counter example: two threads each add to a counter; an interrupt between the load and the store loses an update; counter = counter + 1 compiles to three x86 instructions (mov, add, mov); the terms critical section, race condition, mutual exclusion, atomicity. Used in: layer 2 "How an update is lost", jargon "Interleaving".
  3. F3 [D4 [intro.races]/17] "The execution of a program contains a data race if it contains two potentially concurrent conflicting actions, at least one of which is not atomic, and neither happens before the other … Any such data race results in undefined behavior". Used in: jargon "Data race", breaks.
  4. F4 [D4 [thread.thread.member]/4] "The completion of the thread represented by *this synchronizes with … the corresponding successful join() return". Used in: layer 2 "Splitting work safely".
  5. F5 [R1] hardware_concurrency() printed 4; total 500000500000; 4 chunks. Used in: layer 2, figure 1.
  6. F6 [R2] AAABBB ends with memory 2; ABABAB ends with memory 1. Used in: layer 2.
  7. F7 [R3] race_plain: three totals below 200000 (recorded run); race_tsan: "WARNING: ThreadSanitizer: data race" on global hits at race.cc:10, exit code 66, total 200000. Re-run 2026-10-10: two of three plain runs printed 200000. Used in: forensic lab.
  8. F8 [R4] GCC 13.3.0 -O2 compiled chunksDone.fetch_add(1) to "lock add QWORD PTR [rax],0x1". Used in: hardware section.
  9. F9 [arithmetic] Amdahl: 1/(0.1 + 0.9/4) ≈ 3.08; 1/(0.25 + 0.75/4) ≈ 2.29; 1/(0.05 + 0.95/8) ≈ 5.93; limits 10, 4, 20 — recomputed. Used in: layer 2, worked example, answers.
  10. F10 [D1 ch. 1, 6; D2 ch. 5, 3 (as named)] The shift to multicore (power and heat; diminishing returns); Amdahl's law as stated; cache coherence by invalidation; MSI/MESI, snooping versus directories; false sharing; memory consistency; simultaneous multithreading. Chapters located, text not opened. Used in: jargon, layer 1–3, hardware, breaks.
