C. Facts (keyed to the chapter's claim tags)

  1. F1 [D13 Features, Table 2] "16 internal banks (x4, x8): 4 groups of 4 banks each"; "8 internal banks (x16): 2 groups of 4 banks each"; row addressing 64K (A[15:0]) for x8/x16 and 128K for x4; column addressing 1K (A[9:0]); page size 1 KB (x8), 2 KB (x16); 8n-bit prefetch, BL8. Used in: jargon (DRAM bank), l2-cell, Figure 1 caption.
  2. F2 [D13 refresh, Table 1] "64ms, 8192-cycle refresh up to 85°C" (32 ms above 85 °C); CL/tRCD/tRP per speed grade, e.g. -062E: CL 22, tRCD 13.75 ns, tRP 13.75 ns. Used in: jargon (DRAM), layer 1, layer 3 (refresh).
  3. F3 [D8 NUMA Memory Policy (kernel docs 7.3.0-rc6)] Memory policy "determines from which node the kernel will allocate memory in a NUMA system"; after boot the system default policy is "local allocation" from the node containing the CPU where the allocation takes place; set_mempolicy(), get_mempolicy(), mbind(); MPOL_DEFAULT, MPOL_BIND, MPOL_PREFERRED, MPOL_INTERLEAVE; numactl(8) is "a command line tool" for task and shared-memory policies. Used in: jargon (NUMA, first-touch), l2-numa, NUMA box, Figure 2 caption.
  4. F4 [D8 numa(3) (December 2007)] libnuma: <numa.h>, -lnuma; numa_available() must be called first; numa_max_node, numa_alloc_onnode, numa_run_on_node, numa_bind, numa_node_of_cpu; "The default memory allocation policy for tasks and all memory range is local allocation". Used in: jargon (first-touch), l2-numa, NUMA box.
  5. F5 [D1 ch. 6 / D3 ch. 2, ch. 5 (titles only)] DRAM cell (1T1C), destructive read, activate/precharge and the row buffer, ranks, channel interleaving, controller scheduling and write batching, NUMA latency and link bandwidth, directories across nodes. Chapter text not openable; cited at chapter level. The D13 excerpt lists the ACTIVATE and PRECHARGE command sections by heading only. Used in: jargon (row buffer, channel, controller), l2-cell, l2-par, layer 3, hardware, breaks.
  6. F6 [R1–R3] dram_model: six neighbours 4 hits / 2 misses, time 10, 3/3 per channel; sequential 254/2, 128/128, 260; scattered 0/256, 128/128, 768; stride 64 KiB 0/256, 256/0, 768. threads_bw: 7.53 / 13.09 / 23.17 GB/s. numa_info: node0 CPUs 0-3, one node. Used in: l2-par, l2-bw, l2-numa, layer 3, worked example, forensic lab and key, summary.
