C. Facts (keyed to the chapter's claim tags)

  1. F1 [L2] The Linux implementation computes an ECAM offset as (bus << 20) | (devfn << 12) | (where & 0xfff), where devfn packs the 5-bit device number above the 3-bit function number, i.e. device << 15 and function << 12. This matches the chapter's formula, which is now stated as what Linux does (AH-5) and no longer sits in the unverified box. Used in: layer3 (ECAM).
  2. F2 [D3] Not checked in the specification: the 0xCF8 address format (enable bit 31, bus 23–16, device 15–11, function 10–8, register 7–2); link speeds, widths, payload sizes, ordering rules; enumeration procedure. arch/x86/pci/direct.c was not opened. Stay in the unverified boxes. Used in: layer3.
  3. F3 [L1] Header constants as used by the listings (opened). Used in: jargon, layer2, layer3.
