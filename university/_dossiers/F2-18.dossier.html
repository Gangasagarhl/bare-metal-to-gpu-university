Notes and quotes (paraphrased unless quoted)

  • N4861 6.7.1: "The memory available to a C++ program consists of one or more sequences of contiguous bytes. Every byte has a unique address." A byte holds any member of the basic execution character set and the eight-bit code units of UTF-8 (so at least 8 bits).
  • N4861 7.6.2.4: sizeof of a narrow character type is 1; for other fundamental types implementation-defined. 6.8.1 Table 12 gives minimum widths (int 16, long 32, long long 64) and the storage ordering of the standard integer types.
  • x86-64 psABI 3.1.2 Figure 3.1: char 1, short 2, int 4, long (LP64) 8, long long 8, pointers (LP64) 8 bytes; "the term byte refers to a 8-bit object".
  • Microsoft "Data Type Ranges": the Microsoft C++ 32-bit and 64-bit compilers recognise the listed types; long is 4 bytes.
  • Intel SDM Vol. 1 1.3.1: "Intel 64 and IA-32 processors are “little endian” machines".
  • Clang AddressSanitizer page: use-after-return detection "already enabled on Linux"; GCC 13.3.0 asan_flags.inc sets the default of detect_stack_use_after_return to SANITIZER_LINUX && !SANITIZER_ANDROID; the GCC 13.3 manual (asan-use-after-return) says the check is disabled at run time by default; the older sanitizers wiki page also says it is off by default.
