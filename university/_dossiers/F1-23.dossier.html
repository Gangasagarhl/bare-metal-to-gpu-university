C. Facts (keyed to the chapter's claim tags)

  1. F1 [D3 ch. 4] Machine language is "the fine line where hardware and software meet": a programming tool and part of the hardware platform; it is an agreed formalism for using a processor, registers and memory. Used in: jargon (ISA, machine code), layer 2 "What an ISA defines".
  2. F2 [D3 ch. 4] Registers are small, fast storage inside the processor; immediate addressing puts a constant inside the instruction; the assembler translates mnemonics and symbols into binary and resolves labels, which may be used before they are defined (hence two passes). Used in: jargon (register, immediate, assembler), code walk-through (pass 1 / pass 2).
  3. F3 [D7 table] x0 is "zero", "Zero", immutable; a0–a7 are argument registers. Used in: layer 3 "The zero register".
  4. F4 [D8 objdump] -d prints the assembler mnemonics; -M intel / -M att selects the syntax; with no -M option R3 shows AT&T syntax. Used in: real-ISA section.
  5. F5 [R1] U16 facts: 16-bit words, eight registers with r0 = 0, 256-word data memory, 12 instructions, formats R/I/X, 6-bit two's-complement immediate, branch target = address + 1 + offset; the sum program outputs 29 in 30 instructions; words 0x16E0, 0x64BF, 0xA43B as printed. Used in: jargon, layer 2, worked example, lab.
  6. F6 [R2] The hand-encoded program with 0x6481 at address 4 runs to the 10,000-step limit and prints nothing. Used in: forensic lab.
  7. F7 [R3] x86-64 instructions of 1, 2, 3, 4 and 6 bytes (c3; 01 f7; 8d 04 17; 48 8d 14 f7; 66 0f 1f 44 00 00); every A64 instruction 4 bytes; RISC-V 4-byte (00b506b3) and 2-byte (9d2d) encodings; x86-64 add (%rdi),%rax from memory; ARM64 ldr/add and RISC-V ld/add. Used in: layer 3, real-ISA section, check yourself 7.
  8. F8 [D1 ch. 2, 4 (as named)] ISA versus implementation; load/store style; PC-relative branches; ISA extension and reserved encodings; immediate widths. Chapter located, text not opened. Used in: layer 2, layer 3, breaks, transition.
  9. F9 [D2 ch. 6 (as named)] Architecture versus microarchitecture; decoding as wiring and a decoder. Chapter located, text not opened. Used in: jargon, hardware.
