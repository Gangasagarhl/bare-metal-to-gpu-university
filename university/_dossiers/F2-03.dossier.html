C. Facts (keyed to the chapter's claim tags)

  1. F1 [D2 §8.5, §8.6, §8.7] Selection, iteration and jump statements change the order of execution. Used in: jargon (Control flow).
  2. F2 [D2 §8.5.1] In if, the first substatement runs when the condition is true, the else part when it is false (so in a chain the first true condition wins); an if may have an init-statement. Used in: jargon (else if chain), layer2, layer3.
  3. F3 [D2 §8.5.2] The switch condition is of integral or enumeration type (char is integral); control passes to the matching case label or to default; "case and default labels in themselves do not alter the flow of control"; a switch may have an init-statement. Used in: jargon (switch), layer2, figure, breaks.
  4. F4 [D2 §8.7.1] break terminates "the smallest enclosing iteration-statement or switch statement". Used in: jargon (break), figure, layer2, breaks, answers.
  5. F5 [D2 §8.7.2, §8.6.3] continue passes control to the loop-continuation portion (end of the body); in a for loop the expression (increment) still runs before the condition. Used in: jargon (continue), hardware.
  6. F6 [D2 §8.6.1, §8.6.2, §8.6.4] while tests before each execution (may run zero times); do tests "after each execution of the statement"; range-based for visits each element. Used in: jargon (do-while), layer2.
  7. F7 [D2 §7.6.14, §7.6.15] &&: the second operand is not evaluated if the first is false; ||: not evaluated if the first is true. Used in: jargon (Short-circuit), layer2, answers.
  8. F8 [D2 §9.12.5] The attribute [[fallthrough]]; marks an intended fallthrough and should suppress the warning. Used in: layer2.
  9. F9 [D2 §29.5.5.4, §29.7.4.1.3] A stream converts to bool as !fail(); reaching end of input sets failbit | eofbit, so while (std::cin >> code) ends at the end of input. Used in: layer2.
  10. F10 [D2 §6.4.3] Names declared in an init-statement or condition are local to the if/switch. Used in: layer3.
  11. F11 [D3 §3.8] -Wall enables -Wparentheses (assignment where a truth value is expected); -Wextra enables -Wimplicit-fallthrough=3; C++17 [[fallthrough]]; suppresses it. Used in: jargon (Fallthrough), layer2.
  12. F12 [D3 §3.17] -fno-jump-tables: "Do not use jump tables for switch statements even where it would be more efficient". Used in: layer3.
  13. F13 [D5] cmp sets condition codes; conditional jumps implement if ("Conditional Goto"); loops become conditional jumps back; a dense switch can use a jump table and an indirect jump. Used in: layer3, hardware.
  14. F14 [R1–R7] All outputs and compiler messages are copied from the recorded runs; the build of R5 printed no warning. Used in: throughout.
