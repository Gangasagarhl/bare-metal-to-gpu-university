C. Facts (keyed to the chapter's claim tags)

  1. F1 [D2 §15.3; D3 §2.1, §2.3] #include is replaced by the entire contents of the named file; the quoted form is searched in an implementation-defined manner and falls back to the angle-bracket form; GCC searches the quoted form "first in the directory containing the current file", the angle form in the system directories. Used in: jargon (Header file, #include), layer1.
  2. F2 [D2 §6.2] A declaration is a definition unless, for example, it declares a function without its body. Used in: jargon (Definition), layer2.
  3. F3 [D2 §6.3] "No translation unit shall contain more than one definition of any … class type" (p1); "Every program shall contain exactly one definition of every non-inline function … that is odr-used …; no diagnostic required" (p10); inline functions may be defined in several translation units with the same tokens (p11, p13); otherwise the program is ill-formed, a diagnostic required only for named modules (p15). Used in: jargon (ODR, inline), layer2, layer3, lab.
  4. F4 [D2 §9.2.7] "An inline function or variable with external or module linkage has the same address in all translation units" (note). Used in: jargon (inline), layer2.
  5. F5 [D2 §12.2] Declarations that differ only in return type cannot be overloaded; a different parameter list declares a new overload. Used in: layer2, forensic key.
  6. F6 [D2 §5.1] Each translation unit is translated separately. Used in: breaks.
  7. F7 [D2 §21.3.1] using string = basic_string<char>; — the long name in R3 is std::string. Used in: worked example.
  8. F8 [D3 §2.4] The "wrapper #ifndef" makes the second inclusion skip the whole file. Used in: jargon (Include guard), layer2.
  9. F9 [D3 §2.5] #pragma once "is not recognized by all preprocessors, so you cannot rely on it in a portable program". Used in: layer3.
  10. F10 [D6 §5.1.2, §5.1.5.2] _Z prefix, length-prefixed names, d = double, f = float. Used in: forensic key.
  11. F11 [D7 (Linking)] The linker associates each symbol reference with exactly one definition; relocation fills in addresses using relocation information for the .text section; multiple strong definitions are a linker error. Used in: jargon (Multiple definition), figure, hardware.
  12. F12 [D8 §2] nm: T = text (code) section, U = undefined; c++filt demangles. Used in: figure, layer2, forensic key.
  13. F13 [D9 §3.2] -c compiles without linking; linking combines newly compiled and given object files. Used in: layer2.
  14. F14 [D10 §4.3, §5.1.1, B.9] kilo = 103, milli = 10−3; 1 L = 10−3 m3; t/°C = (t/°F − 32)/1.8; cup (U.S.) = 2.365 882 E+02 mL. Used in: lab note (replaces the former "Not verified" box).
  15. F15 [R1–R8] All commands, symbol tables and linker messages (converter/main.cpp:14:(.text+0x19d), "multiple definition of `print_banner()'", "redefinition of 'struct Recipe'") are copied from the recorded runs. Used in: throughout.
