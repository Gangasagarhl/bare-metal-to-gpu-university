Notes per document (paraphrased): what each document was used for is given in the chapter's Sources list, in the same words as "Used for".

  • D1: the program stored in memory like data; memory as addressable registers, each with an address and a value; the CPU executing instructions in the fetch-execute cycle; a small set of fast registers inside the CPU; the program counter.
  • D3: main memory made of DRAM chips; the register file; the load, operate and store steps of the simple processor model; the program copied from disk to main memory before it runs; caches as staging areas for information the processor is likely to need; the storage hierarchy (slower, larger and cheaper per byte further from the top); multi-core processors.
  • D4: struct, std::vector, std::string and the loop in Listing 1.
  • D5: DRAM and SRAM lose their information when the supply voltage is turned off; nonvolatile memories, including flash-based solid state disks, keep it.
  • D6: caches are small, fast memories holding copies of popular data; the processor itself puts a copy of loaded data into the cache; main memory is larger and slower.
