F1Precise: an adapter that translates debugger requests (halt, read register, write memory, set breakpoint) from the host into JTAG or SWD transactions on the target's debug port; usually paired with host software that acts as a GDB server.D10 About; D10 §20.1able
F2… 1149.1 test access port and boundary-scan architecture: signals TCK (clock), TMS (mode select), TDI (data in), TDO (data out) and optional TRST, a 16-state TAP controller driven by TMS, an instruction register and several data registers shifted serially.D3 §B3.2.2 Table B3-2, §B3.2.3; D1 abstractable
F3Precise: a 16-state finite-state machine advanced on each TCK rising edge by the value of TMS, which selects whether an instruction or a data register is captured, shifted between TDI and TDO, and updated.D3 §B3.2.3 Figure B3-2able
F4Precise: a two-pin (SWDIO bidirectional data, SWCLK clock) packet protocol defined by the Arm Debug Interface architecture; each transaction is a request, an acknowledgement and a 32-bit data phase with parity, addressed to debug-port or access-port registers.D3 §B4.1.1, §B4.2able
F5Precise: in the Arm Debug Interface, the debug port (JTAG-DP or SW-DP) is the external interface, and access ports behind it, such as a memory access port, perform bus transactions on the chip's memory system, including the core's debug registers.D3 §A1.4, §A1.5, §C2.1able
F6… n with a breakpoint instruction (bkpt on Arm), which needs writable code memory; a hardware breakpoint is an address comparator in the core's debug logic (on Armv7-M, the Flash Patch and Breakpoint unit), which works on flash but exists in limited number.D4 C1.11; D9 §7.1, §7.3able
F7Precise: a data-address comparator (on Armv7-M, in the Data Watchpoint and Trace unit) that halts the core after a matching access; because a watchpoint event is asynchronous to the instruction that caused it, the stop is reported after that instruction.D4 C1.8.1able
F8Precise: a packet protocol (read registers, read/write memory, insert breakpoint, continue, stop reply) spoken by GDB and LLDB; probe software and QEMU's -gdb option implement the server side.D5 §E.1 Overview, §E.3 Packets, §E.4 Stop Reply Packets; D6 §GDB usage; D10 §20.1able
