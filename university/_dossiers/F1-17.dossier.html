Fact list (keyed to the chapter's claim tags)

  1. F1 (jargon) The CPU registers named by instructions ( HW202 , "Register (CPU)") are built this way. — source: D5 “Registers”; D2 §3.2.2
  2. F2 (jargon) a control input of a register: at a clock edge, if load = 1 the register takes its data input, otherwise it keeps its value. — source: D5 “Enabled Flip-Flops”
  3. F3 (jargon) a synchronous reset acts only at a clock edge; an asynchronous reset acts at once, without waiting for the clock. — source: D5 “Resettable Flip-Flops”; D8 Description
  4. F4 (jargon) a sequential circuit whose state steps through a fixed sequence, usually binary 0, 1, 2, ..., 2 n − 1 and then wraps to 0. — source: D7 “Counters”
  5. F5 (jargon) a counter whose flip-flops share one clock; the next value is computed by combinational logic (an incrementer) from the current value. — source: D8 Description; D2 §3.2.4
  6. F6 (jargon) a counter in which only the lowest flip-flop is clocked by the clock and each other flip-flop is clocked by the output of the one before it; the bits change at different times. — source: D9 §1, §4; D11 §1.2.2.3
  7. F7 (jargon) a chain of flip-flops in which each flip-flop's input is the previous one's output; a serial input enters at one end at each edge. — source: D7 “Shift Registers”; D10 §1
  8. F8 (jargon) a brief unintended value on a signal, caused by inputs or bits that change at slightly different times. — source: D8 Description
  9. F9 (fig1) The selector's rule is reset first, then load, otherwise keep — source: D5 “Resettable Flip-Flops”; D2 §3.2.4; R1
  10. F10 (fig2) In the synchronous counter the clock reaches every bit; in the ripple counter each bit's output is the next bit's clock — source: D9 §4; D8 Description
  11. F11 (layer2) Layer 2 — the student explanation Registers with load and reset A register of n bits is n D flip-flops sharing a clock — source: D5 “Registers”; D2 §3.2.2
  12. F12 (layer2) To make "keep" possible, a 2-input multiplexer ( F1-12 ) in front of each flip-flop selects D or the flip-flop's own Q, controlled by load — source: D2 §3.2.2
  13. F13 (layer2) An asynchronous reset clears the flip-flop immediately, without waiting for an edge — source: D5 “Resettable Flip-Flops”; D9 §1
  14. F14 (layer2) Synchronous counters A synchronous counter is a register plus an incrementer: next = count + 1 — source: D2 §3.2.4
  15. F15 (layer2) A wrap output (Listing 2, line 11) is 1 during the cycle in which the next edge will take the counter from 15 back to 0; a second counter can use it as its own enable, which is how a two-digit display counts 00 to 99 — source: D8 Description
  16. F16 (layer2) Bit 1 toggles whenever bit 0 falls from 1 to 0, bit 2 whenever bit 1 falls, and so on — source: D9 §1, §4
  17. F17 (layer2) Shift registers In a shift register , flip-flop k takes the output of flip-flop k − 1 at each edge, and a serial input enters at bit 0 — source: D10 §1; D7 “Shift Registers”
  18. F18 (layer3) Then the behaviour can be reasoned about one cycle at a time: at each edge, every register takes the value its input logic computed during the previous cycle — source: D5 “Synchronous Sequential Logic”
  19. F19 (layer3) Clocking a flip-flop from another flip-flop's output, as the ripple counter does, breaks this rule; synthesis and timing tools then treat each such output as a separate clock, and analysis gets harder — source: D11 §1.2.2.3
  20. F20 (layer3) …erilog, the event list of an always block decides what kind of storage you describe. @(posedge clk) describes edge-triggered flip-flops; a list of levels such as @(clk) or @(en or d) describes something that reacts to every change — source: D6 “always Statement”, “D Flip-Flop”
  21. F21 (hardware) How the hardware actually does it The program counter of a processor is a register with load, increment and reset, exactly the kind of circuit in this chapter; F1-21 reads one, and the course project builds it for HW202 — source: D2 §3.2.4
  22. F22 (hardware) The processor's registers (the ones instructions name) are registers in this sense too, grouped into a register file with read and write ports — source: D7 “Multi-ported Memories”
  23. F23 (hardware) Counters appear wherever hardware must count: the textbook's slides name digital clocks and program counters as uses — source: D7 “Counters”
  24. F24 (hardware) Shift registers sit behind serial links, where bits arrive one at a time and are collected into bytes: a shift register is a serial-to-parallel converter — source: D7 “Shift Registers”
  25. F25 (code) Code walk-through All listings live in university/labs/F1-17/ and were run in this build by run.sh with Icarus Verilog; the timing diagrams were drawn from the simulations' VCD files by the university's wave.py tool — source: D4
  26. F26 (transition) What carries over: the flip-flop's rule (store at the edge, hold otherwise) and the adder, unchanged; a counter is literally an adder feeding a register — source: D2 §3.2.4
