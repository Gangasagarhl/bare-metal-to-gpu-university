C. Facts (keyed to the chapter's claim tags)

  1. F1 [D4 objdump] -d "Display the assembler mnemonics for the machine instructions from the input file"; -C "Decode (demangle) low-level symbol names into user-level names"; -M intel / -M att "Select between intel syntax mode and AT&T syntax mode"; --no-show-raw-insn "do not print the instruction bytes". Used in: jargon "Disassembler", layer 2 "Getting the assembly", "Intel versus AT&T syntax".
  2. F2 [D3 §3.11] -O0 "Reduce compilation time and make debugging produce the expected results. This is the default."; -O2 "GCC performs nearly all supported optimizations that do not involve a space-speed tradeoff"; -O3 adds -floop-interchange … -fvect-cost-model=dynamic; -ftree-loop-vectorize listed as enabled at -O2. Used in: jargon "Optimisation level", layer 2 "What optimisation changes", layer 3.
  3. F3 [D5 §3.2.3] INTEGER arguments: "the next available register of the sequence %rdi, %rsi, %rdx, %rcx, %r8 and %r9"; return: "%rax, %rdx"; Figure 3.4: %rbx, %rbp, %r12–%r15 callee-saved; §3.2.2: 16-byte stack alignment, 128-byte red zone. Used in: layer 2 "A reading method".
  4. F4 [D5b "General-purpose registers"] r0–r7 pass arguments and return results; r8 indirect result location; r16/r17 IP0/IP1; r18 platform register; r19–r28 callee-saved; r29 FP; r30 LR. Used in: layer 2 "A reading method".
  5. F5 [D5c tables] a0–a7 argument registers, a0 and a1 also return values; s0–s1 and s2–s11 callee-saved; x0 zero immutable; aggregates larger than 2×XLEN passed by reference. Used in: layer 2 "A reading method".
  6. F6 [D6 [intro.abstract]/1, /8] "conforming implementations are required to emulate (only) the observable behavior of the abstract machine"; observable behaviour = volatile accesses, data written to files, interactive I/O. Used in: jargon "Dead code elimination", breaks, forensic key.
  7. F7 [D6 [expr.pre]/4] An arithmetic expression whose result is not mathematically defined or not in the range of representable values for its type has undefined behaviour. Used in: layer 3 "Signed overflow".
  8. F8 [R1–R7] Register use edi/esi→eax, w0/w1→w0, a0/a1→a0; add at -O2 = lea eax,[rdi+rsi*1]; ret; cmovge / csel / bge for maxOf; sumArray loop bodies as tabulated; -O0 add is 10 instructions; -O3 uses movdqu and paddd; Clang -O2 cmovg and paddd; x86 addresses step 4, 3, … (lea at 4, ret at 7); A64 addresses 0, 4, 8; RISC-V addresses 0, 2, 4; AT&T output without -M matches line for line. Used in: figure 1, layer 2, worked example, hardware section, summary.
  9. F9 [R8] vanish: -O2 prints 0.000 ms; main has the two steady_clock::now() calls at 1085 and 108d with only mov rbx,rax between; calls go through @plt stubs; no backward branch. Used in: forensic lab and key.
  10. F10 [D1, D2 (as named)] cmovcc/csel/paddd/addw/sext.w semantics; the 32-bit register-write rule; endbr64; no conditional move in base RISC-V. Manuals not opened. Used in: jargon, layer 3, unverified box.
