C. Fact list

  • F1 Feedback: two or more systems connected so each influences the other; feedback can cause oscillations if badly designed. Source: D1 §1.1. Used in: Jargon (Feedback); Layer 1; Transition.
  • F2 The basic feedback loop is sensing, computation and actuation. Source: D1 (companion wiki, Ch. 1 summary). Used in: Jargon (Control loop); Layer 2.
  • F3 The control error e = r − y is the difference between the reference and the output. Source: D1 §1.6. Used in: Jargon (Error); Layer 2.
  • F4 On-off control typically makes the controlled variable oscillate; proportional control acts in proportion to the error. Source: D1 §1.6. Used in: Layer 2; Layer 3; Breaks 2.
  • F5 A differential-drive robot moves by independently controlling two wheels; the controls are the left and right wheel speeds; each wheel gives an opposite turning component. Source: D2 §13.1, §13.3.1, §13.4. Used in: Layer 3.
  • F6 The wheeled-robot models assume rolling without skidding. Source: D2 §13.1. Used in: Breaks 2.
  • F7 A reflective sensor contains an infrared emitter and a phototransistor and detects reflective material. Source: D5. Used in: hardware; Jargon (Line follower).
  • F8 The reference kit names the :MOVE Motor with line-following sensors and two driven wheels. Source: K1. Used in: Code note; D4.
  • F9 Line follower output (steer right at rows 2–3, left at row 6; never lost) and swapped-sensor run. Source: R1, R2. Used in: Worked example; forensic.
