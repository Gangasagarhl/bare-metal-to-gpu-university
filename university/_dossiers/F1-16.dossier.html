Fact list (keyed to the chapter's claim tags)

  1. F1 (jargon) a circuit without memory: after the propagation delay, its outputs are a fixed function of its current inputs (the gates, adders and multiplexers of HW102). — source: D2 §3.1
  2. F2 (jargon) a circuit with memory: its outputs depend on its current inputs and on its stored state, which records information about past inputs. — source: D6 “Sequential Circuits”
  3. F3 (jargon) (The robotics and control courses use "feedback" for a different idea: measuring a result and correcting towards a target.) — source: D6 “Bistable Circuit”
  4. F4 (jargon) a level-sensitive storage element: while its enable (or clock) input is at the active level the output follows the data input ("transparent"); otherwise the output holds. — source: D6 “D Latch”
  5. F5 (jargon) a latch made of two cross-coupled gates (NOR gates in this chapter), with inputs S (set, makes Q = 1) and R (reset, makes Q = 0); S = R = 1 is not allowed. — source: D6 “SR Latch”
  6. F6 (jargon) a latch whose output Q follows D while the enable input is 1 and holds its last value while the enable input is 0; it avoids the forbidden input of the SR latch. — source: D6 “D Latch”
  7. F7 (jargon) an edge-triggered storage element; a D flip-flop copies D to Q at the active edge of its clock (here the rising edge) and holds Q at all other times. — source: D6 “D Flip-Flop”; D2 §3.2.1
  8. F8 (jargon) Clocks themselves are the subject of F1-18 . — source: D6 “D Flip-Flop”
  9. F9 (jargon) a plot of signal values (horizontal axis: time) used to show the order of events; in this course they are drawn from real simulation runs. — source: D6 “D Latch vs. D Flip-Flop”
  10. F10 (jargon) a simulation-only module that drives a design's inputs, observes its outputs and (ideally) checks them; it is not itself hardware. — source: D7 “Testbenches”
  11. F11 (jargon) in Verilog simulation a 1-bit signal has four values: 0, 1, x (unknown) and z (not driven) — source: D7 “Z: Floating Output”
  12. F12 (jargon) a state in which a bistable element's output lingers between the two valid levels for an unpredictable time, for example when a flip-flop's input changes too close to the sampling instant. — source: D6 “Metastability”
  13. F13 (jargon) a latch that a synthesis tool creates from a hardware description in which some output is not assigned on every path through the logic, so the description implies "keep the old value". — source: D7 “Latch”; D5 proc_dlatch; R3
  14. F14 (fig1) The table is checked against the simulation in Listing 2 — source: D6 “SR Latch Analysis”; R1
  15. F15 (fig2) The latch is transparent while clk = 1; the flip-flop samples only at rising edges — source: R2; D6 “D Latch vs. D Flip-Flop”
  16. F16 (layer2) Layer 2 — the student explanation Memory needs feedback A combinational circuit computes its outputs from its present inputs only; its gates form no loops — source: D2 §3.1
  17. F17 (layer2) Its outputs then depend on the present inputs and on a stored state — source: D6 “Sequential Circuits”
  18. F18 (layer2) The SR latch In Figure 1, gate g1 computes Q = NOT(R OR Qn) and gate g2 computes Qn = NOT(S OR Q) — source: D6 “SR Latch Analysis”
  19. F19 (layer2) That is metastability — source: D6 “Metastability”
  20. F20 (layer2) S becomes "D AND enable", and R becomes "NOT D AND enable" — source: D6 “D Latch”
  21. F21 (layer2) The flip-flop fixes this: it captures D only at the rising clock edge and holds Q for the whole rest of the period — source: D6 “D Flip-Flop”; D2 §3.2.1
  22. F22 (layer2) Until the next rising edge nothing new can get through — source: D6 “D Flip-Flop Internal Circuit”
  23. F23 (layer3) Its data sheet gives a setup time (D stable before the edge), a hold time (D stable after it) and a clock-to-Q delay (how long Q takes to change) — source: D6 “Timing”
  24. F24 (layer3) If D changes inside the setup-and-hold window, the flip-flop can become metastable, exactly like the SR latch released from S = R = 1 — source: D6 “Metastability”
  25. F25 (layer3) The course textbook's authors avoid latches altogether ("We don't use latches in this text") and warn that a description can create one by accident — source: D7 “Latch”
  26. F26 (layer3) Listing 4 uses the non-blocking assignment q : all flip-flops that share an edge read their inputs first and update afterwards, as real flip-flops do — source: D7 “Blocking vs. Nonblocking Assignment”
  27. F27 (hardware) How the hardware actually does it In silicon, the NOR gates of Figure 1 are made of transistors used as switches, as in F1-09 and F1-10 — source: D8 “Transistors as switches”, “CMOS gates”
  28. F28 (hardware) The textbook's slides call a pair of cross-coupled inverters (the same loop with no S and R inputs) the fundamental building block of other state elements; F1-20 meets the same loop again inside an SRAM cell — source: D6 “Bistable Circuit”
  29. F29 (hardware) A processor contains many flip-flops: its registers ( F1-17 ) and its program counter, which is a register plus counting logic — source: D2 §3.2.4
  30. F30 (code) …ompiled and run in this build by the lab script run.sh in university/labs/F1-16/ , which also turns the simulation's value-change file into a text timing diagram with the university's small Python tool wave.py (in the same folder) — source: D5
  31. F31 (code) The standard way to describe a flip-flop — source: D7 “D Flip-Flop”
  32. F32 (breaks) A metastable flip-flop has an output between the two valid levels for an undetermined time, so it is neither a clean 0 nor a clean 1 — source: D6 “Metastability”
  33. F33 (transition) What carries over: gates, truth tables and delays; a latch is built from the same NOR gates, and its behaviour is traced with the same delay reasoning — source: D6 “SR Latch”
