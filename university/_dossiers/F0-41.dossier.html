C. Fact list

  • F1 Two switches in series must both be closed for current to flow: an AND operation; two in parallel: an OR operation; little tables summarise every combination. Source: D4 ch. 6 pp. 48–54. Used in: Jargon (Switch, Truth table, Series, Parallel); Layers 1–2; Figure 1.
  • F2 Series: current flows through the parts one after another; parallel: each part has the same voltage across it. Source: D7 §10.2. Used in: Jargon (Series, Parallel).
  • F3 A complete path is needed for current. Source: D7 §9.1. Used in: Layer 1; Transition.
  • F4 With no current, a resistor has no voltage across it (V = IR), so an open switch has the whole battery voltage across it. Source: D7 §9.4. Used in: Breaks 2; Layer 2.
  • F5 Virtually all mechanical switches bounce on opening or closing; a debouncer changes its output only after the input is stable. Source: D5. Used in: Layer 3; Breaks 3; hardware.
  • F6 A minimum delay between toggles debounces an input; edge detection compares the button state with its previous state. Source: D6. Used in: Layer 2; Layer 3.
  • F7 The reference kit names the BBC micro:bit V2 with buttons A and B. Source: K1. Used in: Code note; D3.
  • F8 Listing outputs (truth table, toggles at ticks 1, 6, 9; broken toggle). Source: R1, R2. Used in: Worked example; forensic.
