Fact list (keyed to the chapter's claim tags)

  1. F1 (jargon) a circuit storing one bit that can be selected for reading and writing by a word line and connected to one or two bit lines. — source: D4 “Memory Array Bit Cells”; D5 6T cell
  2. F2 (jargon) random-access memory whose cell is a bistable loop of two cross-coupled inverters plus access transistors (six transistors in the common design); "static" means no refresh is needed. — source: D5 6T cell; D4 “SRAM”
  3. F3 (jargon) random-access memory whose cell is one access transistor and one capacitor; the charge leaks, so the cells must be refreshed periodically, and reading disturbs the charge, so a read must be followed by a write-back. — source: D6 §2.2, §2.4; D4 “DRAM”
  4. F4 (jargon) periodic read-and-restore of every DRAM row within a maximum interval set by the part's specification. — source: D6 §2.4
  5. F5 (jargon) the row-select line, driven by the address decoder, that turns on the access transistors of every cell in one row. — source: D6 §2.2; D5 row decoder
  6. F6 (jargon) a column line shared by all cells in a column; SRAM uses a pair (bit line and its complement), DRAM one line per cell column. — source: D5 6T cell; D6 §2.2
  7. F7 (jargon) a differential amplifier on each bit line that resolves the small voltage change caused by a cell into a full logic level (and, in DRAM, restores the cell). — source: D5 sense amplifiers; D6 §2.2
  8. F8 (jargon) a two-dimensional grid of cells with a row decoder driving word lines and column circuits on the bit lines. — source: D4 “Memory Arrays”; D5 row decoder, column circuitry
  9. F9 (jargon) memory that loses its contents without power; SRAM and DRAM are both volatile. — source: D5 memory taxonomy
  10. F10 (fig1) DRAM: the capacitor holds it as charge — source: D5 6T cell; D6 §2.2
  11. F11 (fig2) The decoder ( F1-12 ) turns on one word line; every cell in that row connects to its bit line, and the sense amplifiers turn the small signals into clean bits — source: D4 “Memory Arrays”; D5 sense amplifiers
  12. F12 (layer2) This is the same feedback idea as the latch of F1-16 , without the set and reset gates — source: D4 “SRAM”
  13. F13 (layer2) Two access switches, controlled by the word line, connect q and q̄ to a pair of bit lines — source: D5 6T cell
  14. F14 (layer2) Write: strong drivers put the value on BL and its opposite on BL̄; the word line goes to 1; the drivers are stronger than the cell's inverters and force the loop into the new state — source: D5 write operation
  15. F15 (layer2) Read: the bit lines are prepared (in real chips, precharged) and left undriven; the word line goes to 1; the cell pulls one bit line towards its value, and a sense amplifier decides — source: D5 read operation
  16. F16 (layer2) (The rules for strengths are part of the Verilog standard, D3, whose text was not opened; the run shows how this simulator applies them.) The DRAM cell A DRAM cell is one access transistor and one capacitor (Figure 1, right) — source: D6 §2.2
  17. F17 (layer2) The charge slowly drains away, so every row must be refreshed (read and written back) before it falls below what the sense amplifier can still recognise — source: D6 §2.4
  18. F18 (layer2) Opening a row moves the charge of its cells onto the bit lines and into the sense amplifiers; this destroys the data in the cells, so the sense amplifiers write the values back — source: D6 §2.2
  19. F19 (layer2) Two parts per bit instead of six — source: D5 6T cell; D6 §2.2
  20. F20 (layer2) The address is split: the row part goes to a decoder ( F1-12 ) that turns on one word line; the column part chooses which bit lines go to the output, through multiplexers — source: D5 column circuitry; D4 “Memory Arrays”
  21. F21 (layer2) The lab builds that interface from Verilog registers (a register file, F1-17 ), which is how small memories inside processors are often described in HDL — source: D4 “SystemVerilog Memory Arrays”
  22. F22 (layer3) SRAM needs no refresh; DRAM must be refreshed, but its cell has fewer parts — source: D4 “DRAM”, “SRAM”
  23. F23 (layer3) The textbook's slides call DRAM the main memory of your computer — source: D4 “DRAM”
  24. F24 (layer3) The textbook's slides call DRAM the main memory of your computer , and the 6T SRAM cell is the one used on most commercial chips — source: D5 6T cell
  25. F25 (layer3) In DRAM, opening a row moves the whole row into the sense amplifiers; reading further columns of the same open row is faster than opening a new row — source: D6 §2.2, §2.3
  26. F26 (layer3) The memory controller also has to fit refresh commands between normal accesses ( F1-39 ) — source: D6 §2.3, §2.4
  27. F27 (layer3) The block memories inside FPGAs are synchronous: for example, a vendor's library guide describes its block RAM as "fully synchronous" to its clocks, so data appears after a clock edge — source: D7 RAMB18E1
  28. F28 (layer3) The paper that reported this measured it on real memory modules and evaluated several counter-measures, from more frequent refresh to refreshing the neighbours of a busy row — source: D6 abstract, §6.3, §8
  29. F29 (hardware) How the hardware actually does it The common SRAM cell, the one used on most commercial chips, is six transistors: two inverters of two transistors each, plus two access transistors ( F1-09 showed the transistor as a switch) — source: D5 6T cell
  30. F30 (hardware) The transistors are sized so that the bit-line drivers win a write and the cell is not upset by a read — source: D5 read and write operation
  31. F31 (hardware) It accepts commands such as ACTIVATE (open a row), READ and WRITE (a column of the open row), PRECHARGE (close the row) and REFRESH from a memory controller — source: D6 §2.1–2.4, Table 1
  32. F32 (hardware) That is a job for a state machine of the kind F1-19 introduced — source: D6 §2.3, §2.4
  33. F33 (breaks) Reading a DRAM row destroys the data in its cells; the values survive only because the sense amplifiers write them back — source: D6 §2.2
  34. F34 (breaks) Real cells lose charge through several physical leakage mechanisms — source: D6 §2.4
  35. F35 (breaks) Both SRAM and DRAM are volatile — source: D5 memory taxonomy
  36. F36 (transition) What carries over: the SRAM cell is that same feedback loop, a memory array is decoders and multiplexers from F1-12 around many cells, and a refresh controller is a counter driving an FSM — source: D4 “Memory Arrays”
