C. Facts (keyed to the chapter's claim tags)

  1. F1 [D11 §11.4.1] A cache is divided into cache lines, each with a data block and metadata; the block is the unit of transfer; typical block sizes 16 to 64 bytes; each address maps to exactly one line in a direct-mapped cache; the valid bit; the tag is the high-order bits; the offset selects the byte; offset bits = log2(block size), index bits = log2(number of lines), tag = all remaining bits; index bits are taken from the middle of the address because that spreads clustered data across lines better than high-order bits. Used in: jargon (cache line, tag/index/offset, direct-mapped), layer 1, l2-split, Figure 1 caption.
  2. F2 [D11 §11.4] On a hit the cache serves the access; on a miss the CPU waits for memory and loads the data into the cache; loading into a full cache evicts resident data. Used in: jargon (hit and miss), l2-lookup.
  3. F3 [D11 §11.4.2] Miss types: compulsory (cold-start), capacity, conflict; a fully associative cache may place any region in any line, has the fewest conflicts but the highest lookup and eviction complexity (useful for small structures such as TLBs); a set-associative cache maps each address to one set holding multiple lines (typically 2 to 8). Used in: jargon (set, fully associative, conflict miss), l2-kinds.
  4. F4 [D11 §11.4.3] In a set-associative cache the index selects a set and all lines in that set are checked simultaneously; LRU replacement evicts the least recently used line and needs extra metadata bits per set (one LRU bit for two ways). Used in: jargon (way, set-associative, LRU), layer 1, l2-lookup, Figure 2 caption.
  5. F5 [D1 ch. 6 / D2 ch. 5 / D3 App. B (titles only)] Capacity C = S × E × B; the AMAT formula hit time + miss rate × miss penalty; pseudo-LRU and other approximations in hardware; virtually indexed, physically tagged lookup with S × B ≤ page size; banks, ports, way prediction, miss handling registers; SRAM tag and data arrays with per-way comparators and a multiplexer. Not checked against the chapter texts (not openable); cited at chapter level. Used in: l2-geometry, l2-amat, layer 3, hardware.
  6. F6 [R4] cache_info.sh on the build container: L1d 48K 12 ways 64 B 64 sets; L1i 32K 8 ways 64 sets; L2 2048K 16 ways 2048 sets; L3 266240K 20 ways 212992 sets; arithmetic agrees (64 × 12 × 64 = 49,152). Used in: l2-geometry, Figure 1, Listing 4.
  7. F7 [R1–R3] addr_split: 0x12345 → tag 0x12, set 13, offset 5; 0x0/0x1000/0x2000 all set 0. cachesim: direct-mapped 2 hits/10 misses; 2-way 4/8; fully associative 8/4; sameset 0 hits of 48. conflict.cc: 1.56–1.57 ns for k ≤ 10, 2.91 ns at k = 12, 3.6–4.6 ns from k = 13 at 4096 B spacing; 1.3–1.6 ns at 4160 B. Used in: worked example, code walk-through, forensic lab and key.
