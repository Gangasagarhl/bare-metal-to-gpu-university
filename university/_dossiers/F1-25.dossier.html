C. Facts (keyed to the chapter's claim tags)

  1. F1 [R1] The U16 control table from u16::control(): row 8 "sw 0 1 1 0 1 0 0 0 0 0 add"; row 7 lw; opcodes 0 and 12–15 halt. Used in: layer 2, worked example, answers.
  2. F2 [R2] iverilog -g2012 simulation of control.v with control_tb.v; diff against the C++ table: "no differences" for all 16 opcodes (GNU diffutils 3.10). Used in: layer 2 "Testing hardware against a table".
  3. F3 [R3] Yosys 0.33 synth of control.v: "Number of cells: 30" (generic cells of yosys's own library). Used in: layer 3, summary.
  4. F4 [R4] control_bug.v differs in exactly one row: opcode 8 (sw), RegWrite 1 instead of 0. Used in: forensic lab.
  5. F5 [D1, D2 (as named)] Control as combinational logic from the opcode; don't-care entries; main and ALU decoders in two-level designs; control signals travelling through pipeline registers; always @(*) with defaults to avoid latches. Chapters located, text not opened. Used in: jargon, layer 2, layer 3, hardware.
  6. F6 [D1 App. C, D4 (as named)] Microprogrammed control: control words in a memory, stepped per instruction; hardwired control as gates. Text not opened. Used in: jargon, layer 3.
