C. Facts (keyed to the chapter's claim tags)

  1. F1 [R1] Toy run: RDMA WRITE into a region registered with remote-write permission succeeds; RDMA READ of the same region fails with "remote access error" (no remote-read permission); a WRITE of 12 bytes at address 60 of a region ending at 64 fails with "remote access error" (bounds); SEND without a posted receive fails with "receiver not ready (no receive posted)" and succeeds once A posts a receive, which then also completes on A's side; a key is valid only for its own region even when the address lies inside another. Used in: pictures (Figure 2), layer2 experiments, layer3 permission table, checks
  2. F2 [R2] stale_key: after deregistering and registering the buffer again the key changes; a peer still quoting the old key gets "remote access error" on every operation until it learns the new key. Used in: forensic pack and answer key
  3. F3 [R3] The build machine has no /sys/class/infiniband folder and none of ibv_devinfo, ibv_devices or rdma; the step exits 0 after recording that. Used in: untested-on-hardware box, lab
  4. F4 [D6] Track F lists InfiniBand, RoCE v2, verbs, queue pairs and memory registration under "Inter-node networks" and GPUDirect RDMA as its own topic; DS401 names Soft-RoCE as one lab option; the Track F hardware note and build/KIT.md name two NVIDIA ConnectX-6 Lx NICs cabled back to back. Used in: layer2, layer3, untested box (what is needed)
