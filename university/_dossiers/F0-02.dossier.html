Notes per document (paraphrased): what each document was used for is given in the chapter's Sources list, in the same words as "Used for".

  • D1: "bit" as a contraction of binary digit; the two binary digits 0 and 1; every additional bit doubles the number of codes (2 to the power of the number of bits); the meaning of bits is always understood from context.
  • D2: the C++ features in Listings 1 and 2 (std::vector, std::string, loops, reading with std::cin).
  • D3: two-valued signals (for example a high or low voltage on a wire), stored in very large numbers on one chip; blocks of 8 bits, or bytes; a byte's value ranges from 00000000 to 11111111 in binary.
  • D4: the binary system is based on 2; place values are powers of two (worked example: 10011 is 19).
  • D5: the same bits can stand for different things; only the context tells them apart.
