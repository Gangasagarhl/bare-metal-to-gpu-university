C. Facts (keyed to the chapter's claim tags)

  1. F1 [D1 §7.2.1.1; D2 §19.3] On failure assert writes "the text of the argument, the name of the source file, the source line number, and the name of the enclosing function" to standard error, then "calls the abort function"; C++'s <cassert> has the same contents as C's <assert.h>. Used in: jargon (Assertion), hardware.
  2. F2 [D1 §7.2] With NDEBUG defined where <assert.h> is included, assert is #define assert(ignore) ((void)0): the argument is not evaluated. Used in: jargon (NDEBUG), layer2, forensic key.
  3. F3 [D1 §7.22.4.1; D6 (abort(3))] abort raises SIGABRT and the process terminates abnormally. Used in: hardware.
  4. F4 [D6 (Bash §3.7.5; signal(7))] "When a command terminates on a fatal signal whose number is N, Bash uses the value 128+N"; zero exit status means success; SIGABRT is 6 on x86 and ARM, so 128 + 6 = 134. Used in: layer2, hardware (replaces the former "Not verified" box).
  5. F5 [D2 §9.1] A static_assert whose condition is true "has no effect"; otherwise the program is ill-formed and the diagnostic includes the message. Used in: jargon (static_assert), hardware.
  6. F6 [D4 I.5, I.6] State preconditions; preconditions written with assert() "might have the wrong semantics (do you always want to abort in debug mode and check nothing in productions runs?)". Used in: jargon (Precondition), layer3.
  7. F7 [D5] Rounding error is "the characteristic feature of floating-point computation"; rounding to nearest errs by at most .5 ulp; double p = 53; an error bound for equality "is hardly a cure-all". Used in: jargon (Floating-point tolerance), layer2, answers.
  8. F8 [D7 B.9] t/°C = (t/°F − 32)/1.8, so 32 °F = 0 °C, 212 °F = 100 °C and −40 °F = −40 °C. Used in: layer2, worked example (replaces "water freezes/boils", which no opened source supported).
  9. F9 [D3 ch. 6] Teaching advice about tests (test as you write, boundary cases, automation); the book's table of contents shows these topics; no technical fact rests on it. Used in: jargon (Unit test, Edge case), layer1, layer2, breaks.
  10. F10 [R1–R8] All outputs, assertion messages (assert_fail.cpp:12, test_units.cpp:34) and exit codes (0, 134) are copied from the recorded runs. Used in: throughout.
