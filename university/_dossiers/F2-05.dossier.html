C. Facts (keyed to the chapter's claim tags)

  1. F1 [D1 §12.1, §12.2, §12.2.2] vector elements are "stored contiguously in memory"; push_back() grows it, capacity() counts slots; "The standard-library vector does not guarantee range checking"; at() checks. Used in: jargon (Container, at()), layer3.
  2. F2 [D2 §22.2.1, §22.2.3] Containers store objects; size() counts elements (unsigned size_type); push_back appends, pop_back removes the last; a[n] is *(a.begin() + n); "at() throws out_of_range if n >= a.size()". Used in: jargon (push_back, size(), at()), figure, layer1, layer2, answers.
  3. F3 [D2 §23.3.1] Past-the-end values are not dereferenceable, so reading element size() through [] is undefined behaviour. Used in: jargon (Out-of-bounds access), breaks.
  4. F4 [D2 §21.3.2, §7.3.8, §21.4.2.7] npos is size_type(-1), which converts to the largest value of the unsigned type; find returns the position or, "Otherwise, returns npos". Used in: jargon (npos), answers.
  5. F5 [D2 §21.3.2.7.3] substr(pos, n) copies the smaller of n and size() - pos characters starting at pos; throws out_of_range if pos > size(). Used in: jargon (substr), layer2.
  6. F6 [D2 §21.3.4; D8 §7.22.1.4] stoi calls strtol, which converts "the initial portion of the string"; to_string formats like sprintf "%d". Used in: layer2.
  7. F7 [D2 §21.3.2.7.4, §21.4.2.7, §21.2.3.1] String comparison compares character by character with char_traits<char>, whose lt is defined as < for unsigned char. Used in: layer2.
  8. F8 [D2 §22.3.7.1] array<T, N> stores N elements, size() == N always; it is an aggregate list-initialized with up to N elements. Used in: layer2, layer3.
  9. F9 [D2 §22.3.11.1, §22.3.11.3, §22.3.11.5] vector is a contiguous container; capacity() is the number of elements it can hold without reallocation; "Reallocation invalidates all the references, pointers, and iterators". Used in: layer3, breaks.
  10. F10 [D2 §21.3.2.4; D6] size() counts char-like objects (bytes for std::string); in UTF-8 a character takes one to four bytes. Used in: breaks.
  11. F11 [D2 §8.6.4] A range-based for visits every element of the range. Used in: layer2.
  12. F12 [D3 §3.8, §3.12] -Wsign-compare is enabled by -Wall in C++; -fsanitize=address instruments memory accesses "to detect out-of-bounds and use-after-free bugs". Used in: jargon (AddressSanitizer), layer2.
  13. F13 [D5] AddressSanitizer = compiler instrumentation + run-time library; memory around allocations ("red zones") is poisoned and checked through shadow memory. Used in: jargon (AddressSanitizer), hardware.
  14. F14 [D7 (Machine-Level Programming III)] An array occupies a contiguous region of Length × sizeof(Type) bytes; element i of an int array is at x + 4*i. Used in: hardware.
  15. F15 [R1–R7] All outputs, the ASan report ("heap-buffer-overflow", "READ of size 4", "0 bytes after 16-byte region", exit code 1) and the compiler messages are copied from the recorded runs (machine-specific numbers replaced by placeholders, as stated in the chapter). Used in: throughout.
