C. Facts (keyed to the chapter's claim tags)

  1. F1 [D1 §3.1.1] SDA and SCL are bidirectional open-drain lines with pull-up resistors; the wired-AND makes the line low whenever any device pulls it low. Confirmed. Used in: jargon (open-drain), layer1, layer2.
  2. F2 [D1 §3.1.4, §3.1.5, §3.1.10] START = SDA high-to-low while SCL high; STOP = SDA low-to-high while SCL high; bytes are 8 bits MSB first, each followed by an acknowledge bit; the first byte after START carries the 7-bit target address and the R/W bit; repeated START without an intervening STOP. Confirmed. Used in: jargon (I2C), layer2, worked example 1.
  3. F3 [D1 §3.1.6] The receiver pulls SDA low during the ninth clock to acknowledge (ACK); leaving it high is NACK, which means no receiver at the address, the receiver cannot accept more data, or the controller signals the end of a read. Confirmed. Used in: jargon (ACK/NACK), layer2.
  4. F4 [D1 §3.1.8, §3.1.9] Arbitration: a controller that sends a 1 but reads a 0 has lost and must stop; clock stretching: a target holds SCL low to make the controller wait. Confirmed. Used in: layer3.
  5. F5 [D1 §3.1.16] Bus clear: if SDA is stuck low, the controller sends nine clock pulses to release it, then a STOP. Confirmed; the chapter's "toggle SCL until SDA is released" is a looser wording of the same procedure. Used in: layer3 (stuck bus).
  6. F6 [D1 §5] Bus speeds by mode: 100 kbit/s, 400 kbit/s, 1 Mbit/s, 3.4 Mbit/s, 5 Mbit/s. Now stated in the chapter (moved out of the "no speeds given" box). Used in: layer3.
  7. F7 [D4b (catalogue abstract)] Classical CAN: bit rates up to 1 Mbit/s and payloads up to 8 bytes; CAN FD: higher bit rates, longer payloads. Stated with the catalogue page as source (ruling C2). Used in: layer3.
  8. F8 [D5 §4.2, §6.1, §6.7] PulseView: set the sample rate to at least twice the highest frequency; add a protocol decoder (I²C) and assign SCL/SDA; export annotations. Confirmed for version 0.4.2; the hardware step itself is untested. Used in: lab steps 5–6.
  9. F9 [D2, D3, D4a] Not checked: SPI modes CPOL/CPHA, UART 16× sampling and divisor, CAN acknowledge slot, bit stuffing and resynchronisation. Flagged in an unverified box. Used in: layer2, layer3, figure 2 table.
  10. F10 [L1–L3] Header constants as used (opened). Used in: layer2, layer3, listings.
