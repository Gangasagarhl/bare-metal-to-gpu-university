C. Fact list

One entry per tagged claim in the chapter (the claim text as it stands after the verification pass, the tag that supports it, and the chapter section). Every document section named in a tag was opened and the fact was found there; R-ids are this build's lab runs.

  1. F1 Simple words: A list of values of the same type that can grow. Analogy: A row of numbered jars on a shelf, and you can add more jars at the end. Precise: The standard library container from <vector> that stores elements in order; size() gives the number of elements and push_back adds one at the end (R1). source: R1, D1 §12.2, D4 §22.2.3; used in: F0-35-jargon
  2. F2 Simple words: A list with a fixed number of values. Analogy: An egg box: always the same number of places. Precise: The standard library container from <array> whose size is part of its type, for example std::array<std::string, 3> (R3). source: R3, D4 §22.3.7.1; used in: F0-35-jargon
  3. F3 Simple words: One value inside a list. Analogy: One jar in the row. Precise: One of the values stored in a container such as std::vector. source: R1, D1 §12.2; used in: F0-35-jargon
  4. F4 Simple words: The position number of an element. Counting starts at 0. Analogy: The number painted on a jar: jar 0, jar 1, jar 2. Precise: The position of an element in a container, from 0 up to size() − 1; list[0] is the first element (R1). source: R1, D1 §12.2; used in: F0-35-jargon
  5. F5 Simple words: A for loop that visits every element of a list, one by one, without an index. Analogy: Walking along the shelf and looking into each jar in turn. Precise: for (int score : scores) { ... } runs the block once for each element, with the loop variable holding that element (R2). source: R2, D1 §12.2, D4 §8.6.4; used in: F0-35-jargon
  6. F6 Simple words: Asking for a list position that does not exist. Analogy: Reaching for jar 3 on a shelf that has only jars 0, 1 and 2. Precise: Using an index that is not less than size(); the member function at() checks and throws std::out_of_range, which stopped the program in R4 with exit code 134 (an exception that nobody catches makes the program call std::terminate, which by default calls abort()). source: R4, D1 §12.2.2, D4 §22.2.3, §14.6.1, §17.9.4.1; used in: F0-35-jargon
  7. F7 A vector is declared with the type of its elements in angle brackets: std::vector<std::string> list = {"rice", "beans", "onions"};. You need #include <vector>. Each value in it is an element. list.size() gives the number of elements: 3 here. source: R1, D1 §12.2; used in: F0-35-layer2
  8. F8 You read an element by its index in square brackets: list[0] is "rice". Valid indexes go from 0 to size() - 1. list.push_back("lemons") adds a new element at the end; afterwards the size was 4 and "lemons" had index 3. source: R1, D1 §12.2, D4 §22.2.3; used in: F0-35-layer2
  9. F9 To visit every element, you can count through the indexes: for (std::size_t i = 0; i < list.size(); ++i). The type std::size_t is a whole-number type made for sizes: it has no negative values, and it is big enough for the size of any object. Note the <: the last index used is size() - 1. source: R1, D4 §17.2.4; used in: F0-35-layer2
  10. F10 If you do not need the index, a range-based for loop is shorter and cannot go out of range: for (int score : scores) runs once per element, with score holding a copy of that element. Listing 2 uses it to compute a total, a count and the best score. source: R2, D1 §12.2, D4 §8.6.4; used in: F0-35-layer2
  11. F11 A std::array has its length in its type: std::array<std::string, 3> meals always holds exactly 3 strings. It has size() and can be visited with the same loops, but it has no push_back. source: R3, D4 §22.3.7.1, §22.2.3; used in: F0-35-layer2
  12. F12 Square brackets do not check the index. The member function at() does: eggs_per_box.at(3) on a vector of size 3 stopped the program with the message "vector::_M_range_check: __n (which is 3) >= this->size() (which is 3)" and exit code 134. source: R4, D1 §12.2.2, D4 §22.2.3; used in: F0-35-layer2
  13. F13 … s" is missing from the output, although that statement ran before the crash. The program collected its output in a waiting area (a buffer) to print it later, and the crash came first. When the same program used std::endl, which empties the buffer at once, the line appeared. So when a program crashes, its last printed lines may be missing: the crash may have happened later than the output suggests. source: R4, R5, D4 §29.7.5.4; used in: F0-35-layer3
  14. F14 What about square brackets with a bad index? The C++ rules do not promise any particular result: the program might print a strange value, crash, or seem to work. That is why this course uses at() when an index could be wrong, and why our build uses AddressSanitizer (-fsanitize=address), a tool that watches memory use while the program runs. source: D1 §12.2.2, D2 §3.12; used in: F0-35-layer3
  15. F15 In for (const std::string& meal : meals) (Listing 3), the & lets the loop look at each string in place, without copying it, and const promises not to change it. You will learn this properly in SP101. source: D4 §8.6.4, §9.4.3, §7.2.1; used in: F0-35-layer3
  16. F16 A vector keeps its elements next to each other in memory, like jars side by side on one shelf. To find element i, the program starts at the address of element 0 and moves forward i element-widths. That is why counting starts at 0: element 0 is zero steps from the start. When a vector grows beyond the space it has, it moves its elements to a bigger shelf; you do not see this happen. source: D1 §12.2, D4 §22.2.3, §22.3.11.1, §22.3.11.5; used in: F0-35-hardware
  17. F17 A shopping list can hold rice and a phone number at the same time. A vector holds elements of one type only: std::vector<int> holds only whole numbers. source: D1 §12.2; used in: F0-35-breaks
  18. F18 Reaching for a jar that is not there, you would feel the empty shelf and stop. In C++, square brackets do not check; only at() checks, and it stops the program when the index is bad. source: R4, D1 §12.2.2; used in: F0-35-breaks
  19. F19 Adding a jar to a real shelf never moves the other jars. A growing vector may move all its elements to a new place in memory, which matters in later courses. source: D4 §22.3.11.5; used in: F0-35-breaks
  20. F20 v.at(3) checks and stops the program with std::out_of_range (R4); v[3] does not check, and the result is not defined by the C++ rules. source: R4, D1 §12.2.2; used in: F0-35-answers
