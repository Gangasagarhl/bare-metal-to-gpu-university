C. Fact list

  • F1 A diode allows current in one direction only, like a one-way valve; forward bias conducts, reverse bias blocks. Source: D5 §9.7; D4 §9.4. Used in: Jargon (LED, Diode); Layer 1; hardware.
  • F2 In forward bias, small changes in voltage give large changes in current (nonohmic behaviour). Source: D5 §9.7; D4 §9.4. Used in: Layer 3; Breaks 2; LED needs a resistor.
  • F3 A resistor is ohmic and limits current by V = IR; in a series loop the same current flows through each part. Source: D4 §9.4, §10.2. Used in: Layer 2; Jargon (Resistor).
  • F4 Around a closed loop the voltage changes add to zero, so the resistor gets the battery voltage minus the LED forward voltage. Source: D4 §10.3. Used in: Layer 2.
  • F5 A resistor gives off energy as heat. Source: D4 §9.5. Used in: Breaks 3.
  • F6 A voltmeter is connected in parallel with the part it measures. Source: D4 §10.4. Used in: Jargon (Multimeter).
  • F7 An LED datasheet lists, per part, the colour and semiconductor material, a forward-voltage range per colour and an absolute maximum forward current; different colours use different materials. Source: D6. Used in: Jargon (Forward voltage, Datasheet); hardware; Layer 2.
  • F8 The reference kit names the Fluke 17B+ multimeter; it does not name the LED, resistor or battery holder. Source: K1. Used in: Code note; D3.
  • F9 Listing 1 and meter.cpp outputs (20, 4, 40 mA cases; dark LED evidence). Source: R1. Used in: Worked example; forensic.
