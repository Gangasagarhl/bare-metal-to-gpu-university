Fact list (keyed to the chapter's claim tags)

  1. F1 (jargon) a sequential circuit with a finite set of states, a state register holding the current state, next-state logic that computes the next state from the current state and inputs, and output logic. — source: D5 “Finite State Machines (FSMs)”
  2. F2 (jargon) the value held in the state register; it summarises everything about past inputs that the machine needs for its future behaviour. — source: D5 “Finite State Machine (FSM)”
  3. F3 (jargon) a directed graph whose nodes are states and whose edges are transitions, labelled with the input conditions that cause them (and, for Mealy machines, the outputs). — source: D5 “Moore FSM Example”, “Mealy FSM Example”
  4. F4 (jargon) a table listing, for each current state and input combination, the next state (and outputs). — source: D5 “FSM Design Procedure”
  5. F5 (jargon) combinational logic computing the next state from the current state and the inputs; it is stored into the state register at the clock edge. — source: D5 “Finite State Machines (FSMs)”
  6. F6 (jargon) an FSM whose outputs are a function of the current state alone; outputs change only after a clock edge. — source: D5 “Finite State Machines (FSMs)”
  7. F7 (jargon) an FSM whose outputs are a function of the current state and the current inputs; it can respond in the same cycle, at the cost of outputs that follow input changes between edges. — source: D5 “Mealy FSM Example”
  8. F8 (jargon) an assignment of binary codes to states; binary encoding uses ⌈log 2 (number of states)⌉ flip-flops, one-hot encoding uses one flip-flop per state. — source: D5 state-encoding slides; W1
  9. F9 (jargon) a code the state register can hold but the design never meant to use; the designs in this course give it a defined next state through a default branch. — source: D6 “Combinational Logic using case”
  10. F10 (fig1) In a Moore machine the outputs come from the state alone; a Mealy machine adds the dashed path — source: D5 “Finite State Machines (FSMs)”
  11. F11 (fig2) Every state has exactly one arrow for 0 and one for 1 — source: D5 “Moore FSM Example”; R1
  12. F12 (layer2) Layer 2 — the student explanation Three parts An FSM has a state register of k flip-flops, next-state logic and output logic (Figure 1) — source: D5 “Finite State Machines (FSMs)”
  13. F13 (layer2) Moore and Mealy In a Moore machine , outputs depend only on the state, so they change only right after a clock edge and stay steady for the whole cycle — source: D5 “Finite State Machines (FSMs)”
  14. F14 (layer2) In a Mealy machine , outputs depend on the state and the present inputs — source: D5 “Mealy FSM Example”
  15. F15 (layer2) It follows the usual textbook steps — source: D5 “FSM Design Procedure”
  16. F16 (layer2) The next-state logic then reads "if timer ≥ 5 and a car is waiting, go to yellow" — source: D5 “Factored FSMs”
  17. F17 (layer3) One-hot encoding (one flip-flop per state, exactly one of them 1) uses more flip-flops but often simpler, faster next-state and output logic; synthesis tools may re-encode a state machine they recognise — source: D5 state-encoding slides; D3 fsm, fsm_recode
  18. F18 (layer3) Listing 3's default sends any unknown code to an all-red state — source: D6 “Combinational Logic using case”
  19. F19 (layer3) The Yosys tool used in this course has a command, sat , that can attempt to prove that a signal always has a given value, and with temporal induction that it keeps it forever — source: D3 sat
  20. F20 (hardware) When the synthesis tool reads Listing 3, the state register becomes three flip-flops with a reset, and the case statements become gates ( F1-21 shows such a report) — source: D3 synth, proc
  21. F21 (hardware) When one machine grows too large, the textbook's slides split it into several smaller FSMs that talk to each other ("factored FSMs") — source: D5 “Factored FSMs”
  22. F22 (transition) What carries over: one register on one clock, one step per edge, and combinational logic between edges that must finish within the period — source: D5 “Synchronous Sequential Logic”
