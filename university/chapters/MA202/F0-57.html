Story hook

Analogy

Every evening, Mei and her three cousins each toss a coin to decide who helps with the dishes. Whoever gets heads helps. Mei writes one number on the kitchen scoreboard each evening: how many helpers there were. Some evenings it is 1, some evenings 3, once it was 0 and everyone cheered.

After two months the scoreboard is full of numbers. Mei draws a bar for each possible number, 0 to 4, as tall as the number of evenings it happened. The bars form a shape: low at 0 and 4, highest at 2. Her cousin Sami asks whether the shape would be the same next year. "Not exactly the same bars," says Mei, "but the same shape. The coins do not change."

The number Mei writes each evening is a random variable. The shape that the coins produce in the long run is its distribution. Every sensor reading, every benchmark time and every robot's position estimate in this university is a random variable with a distribution. This chapter teaches how to describe them.

What you will be able to do

  • Define a random variable as a number attached to each outcome of an experiment, and tell discrete from continuous ones.
  • Write the probability mass function (PMF) and the cumulative distribution function (CDF) of a discrete random variable, and use the CDF to compute range probabilities.
  • Use the Bernoulli, binomial and uniform distributions, by formula and in C++.
  • Explain a probability density function (PDF) as "probability per unit", and compute probabilities of a continuous variable as areas.
  • Build a histogram that estimates a distribution from data, choosing bins that cover every value.
  • Diagnose a histogram that silently drops readings and hides a sensor's saturation.
Jargon box
Random variable
Simple words: a number that depends on how a random experiment turns out. Analogy: the number Mei writes on the scoreboard after the coin tosses. Precise: a function X from the sample space S to the real numbers; X(s) is the value for outcome s. Written with a capital letter; its possible values with small letters (X = k). D1
Discrete and continuous random variables
Simple words: discrete ones take separate values you can list (0, 1, 2, …); continuous ones can take any value in a range. Analogy: the number of helpers versus the exact time the kettle takes to boil. Precise: X is discrete if its possible values form a finite or countable list; X is continuous if it has a probability density function (below), so that every single value has probability 0. D1
Distribution
Simple words: the full description of which values a random variable takes and how often. Analogy: the shape of Mei's scoreboard bars after many evenings. Precise: the assignment of probabilities P(X ∈ A) to sets A of values; it is fixed by the PMF (discrete), the PDF (continuous) or the CDF (both). D1
Probability mass function (PMF)
Simple words: a table: each possible value and its probability. Analogy: the bars, scaled so that all bars together make 1. Precise: p(x) = P(X = x) for a discrete X; p(x) ≥ 0 and the p(x) over all possible x add up to 1. D1
Cumulative distribution function (CDF)
Simple words: the probability of getting this value or less. Analogy: stacking the bars from the left and reading the height of the stack so far. Precise: F(x) = P(X ≤ x), defined for every real x; it rises from 0 to 1 and never goes down. P(a < X ≤ b) = F(b) − F(a). D1
Bernoulli and binomial distributions
Simple words: Bernoulli is one yes/no trial; binomial counts the yeses in n identical, independent trials. Analogy: one cousin's coin; the number of helpers among four cousins. Precise: X ~ Bernoulli(p) takes 1 with probability p and 0 with probability 1 − p. X ~ Binomial(n, p) has P(X = k) = C(n, k) pk (1 − p)n − k for k = 0, …, n. D1
Uniform distribution
Simple words: every value in a range is equally likely. Analogy: the moment the washing machine finishes, if all you know is "some time in the next 20 minutes". Precise: discrete uniform on {a, …, b}: each value has probability 1/(b − a + 1). Continuous uniform on [a, b]: density 1/(b − a) inside the interval and 0 outside. D1
Probability density function (PDF)
Simple words: for continuous values, how much probability there is per unit of the value, like people per square metre. Analogy: how crowded the scoreboard would look if you made the bars infinitely thin. Precise: a function f(x) ≥ 0 with total area 1 such that P(a ≤ X ≤ b) is the area under f between a and b. A density value can be larger than 1; an area cannot. D1
Histogram
Simple words: a bar chart of how many data values fall into each of several equal ranges (bins). Analogy: Mei's scoreboard bars. Precise: for bins [bi, bi+1) covering the data, the counts ni; dividing by N gives frequencies (estimates of probabilities) and dividing by N × width gives a density estimate. Every value must fall into exactly one bin. D1W1
Saturation (sensor)
Simple words: when the quantity is bigger than a sensor can measure, the sensor keeps reporting its largest (or smallest) possible reading. Analogy: a measuring jug that is full: pour in more and it still shows "full". Precise: the condition in which the input is outside the measurable range, so the output stays at the end code of the converter; also called clipping. Saturated readings are not the true value. D2

The idea in pictures

Figure 1 shows Mei's random variable, X = the number of heads in 4 fair coin tosses, in two ways. On the left the PMF: one bar per possible value. On the right the CDF: a staircase that climbs by the height of each bar as you move right. The PMF answers "how likely is exactly this value?"; the CDF answers "how likely is this value or less?".

Figure 2 is about continuous variables. There are no bars for single values any more, because a single exact value such as 0.3000… has probability 0. Instead there is a density curve, and probability is the area under it. The solid line is the uniform density on [0, 1); the shaded area between 0.2 and 0.5 is P(0.2 < U < 0.5) = 0.3. The dashed triangle is the density of the sum of two such variables, which Listing 2 also measures.

Layer 1 — the kid explanation

In F0-56 you listed the outcomes of an experiment, such as the 16 ways four coins can land. Often you do not care about the whole outcome. Mei does not care which cousins got heads, only how many. A random variable is that number: one number for each outcome.

Some random variables count things: helpers, sixes, broken parts. You can list their values: 0, 1, 2, 3, 4. For those you can make a table with each value and its chance. That table is the distribution. Its chances always add up to 1, because one of the values must happen.

Other random variables measure things: how long the kettle takes to boil, the temperature on the windowsill. They can be any number in a range, like 183.47 seconds. Then you cannot list every value. You use a curve instead, and the chance of landing in a range is the area under the curve over that range.

In real life you do not know the true distribution. You collect data and draw a histogram: you split the range into equal boxes, count how many values fall in each box, and draw bars. With enough data, the histogram looks more and more like the true distribution. But every value must land in some box. A box that is missing hides part of the story, as the forensic lab shows.

Layer 2 — the student explanation

A random variable is a function

Formally, X is a function from outcomes to numbers. For four coin tosses, the outcome HTHH maps to X = 3. Many outcomes can map to the same value: four outcomes give X = 1 (HTTT, THTT, TTHT, TTTH). The event "X = 1" is the set of those outcomes, so P(X = 1) = 4/16. This is why random variables inherit all the rules of F0-56: statements about X are events. D1R1

PMF and CDF

For a discrete X, the PMF lists p(k) = P(X = k). For Mei's four coins it is 1/16, 4/16, 6/16, 4/16, 1/16 for k = 0 to 4 (run R1, which finds the counts 1, 4, 6, 4, 1 by going through all 16 bit patterns). The CDF adds them up from the left: F(0) = 1/16, F(1) = 5/16, F(2) = 11/16, F(3) = 15/16, F(4) = 1. Range questions become one subtraction: P(1 ≤ X ≤ 3) = F(3) − F(0) = 14/16 = 0.875. D1R1R4

Three named distributions

  • Bernoulli(p): one trial, 1 with probability p, 0 otherwise. A single coin, a single "is this part faulty?" check, a single "did the packet arrive?".
  • Binomial(n, p): the number of successes in n independent Bernoulli(p) trials. Its PMF is P(X = k) = C(n, k) pk (1 − p)n − k. The C(n, k) counts which k of the n trials succeed (F0-56); pk(1 − p)n − k is the probability of any one such pattern, by the multiplication rule for independent trials. For n = 10 and p = 0.5, P(X = 5) = 252/1024 ≈ 0.246.
  • Uniform: discrete on a list of equally likely values (one die face), or continuous on [a, b] with density 1/(b − a).

Each of these comes with assumptions you must check before using it. Binomial needs a fixed number of trials, each with the same p, and independence. Four cousins with four fair coins satisfy that. "The number of rainy days next week" does not: rainy days cluster. D1R4

Continuous variables: density and area

For a continuous X, P(X = x) = 0 for every single x, so a PMF is useless. The PDF f(x) takes its place: P(a ≤ X ≤ b) is the area under f from a to b, the total area is 1, and f(x) ≥ 0. Because single points have probability 0, it does not matter whether you write < or ≤ for a continuous variable. The CDF still works: F(x) = P(X ≤ x) is the area to the left of x. D1

Example: the washing machine will finish at a time T uniformly distributed in the next 20 minutes. The density is 1/20 = 0.05 per minute on [0, 20]. P(T < 5) is a rectangle 5 wide and 0.05 tall: 0.25. P(8 < T < 14) = 6 × 0.05 = 0.3. A density's unit is "probability per unit of x" (here per minute), which is why it can exceed 1 when x is measured in small units. W1R4

Histograms estimate distributions

Given N data values, choose bins of equal width w that cover the whole range of the data, count ni values in bin i, and plot ni/N (frequency) or ni/(N w) (density). The density version can be laid directly over a PDF. Run R2 did this for 10,000 simulated uniform values: every bin of width 0.1 held between 980 and 1032 values, so the density estimates lie between 0.98 and 1.032, close to the true density 1. The frequency of 0.2 < U < 0.5 was 0.2974 against the exact area 0.3. D1R2

Two choices decide whether a histogram tells the truth. The bin edges must cover every value, including the smallest and the largest, and each value must land in exactly one bin; the convention used here is that a bin includes its left edge and excludes its right edge, except the last bin, which also includes the maximum. The bin width trades detail against noise: very narrow bins have few values each and look jagged; very wide bins hide shape. There is no single correct width; report the one you used. W1D1

Layer 3 — the engineer's depth

Functions of random variables are random variables. If U1 and U2 are independent and uniform on [0, 1), then S = U1 + U2 is a new random variable with its own distribution, and it is not uniform: its density is the triangle of Figure 2, f(s) = s for 0 ≤ s < 1 and 2 − s for 1 ≤ s ≤ 2. Run R2's histogram of S shows that shape: density estimates near 0.1 in the outer bins and near 0.91 in the two middle bins (each bin averages the triangle over its width, so the middle bins sit below the peak value 1). Adding more independent variables makes the shape rounder; F0-59 shows where that leads. D1R2

The CDF is the universal description. Every random variable, discrete, continuous or mixed, has a CDF. Mixed variables are common in engineering: a sensor that reads a continuous value most of the time but sticks at its maximum code when overloaded has a CDF with a jump at the maximum. A histogram that excludes the maximum code removes exactly that jump (forensic lab). D1R3

Quantiles invert the CDF. The value x where F(x) first reaches 0.5 is the median; where it reaches 0.9, the 90th percentile. F0-63 builds benchmark reporting on exactly this idea, using the CDF of measured run times. D1

Simulating a distribution. If U is uniform on (0, 1) and F is a continuous, strictly increasing CDF, then X = F−1(U) has CDF F. This "inverse transform" is one standard way of turning uniform random numbers into any other distribution. Listing 2's uniform01 produces U by taking a 32-bit engine output r and computing (r + 0.5) / 232: the centre of one of 232 equal slices of (0, 1), never exactly 0 or 1. D1W1

How the hardware actually does it

A computer never stores a truly continuous value. A sensor's analog-to-digital converter delivers one of a fixed set of integer codes, and a double holds one of a finite set of binary fractions. Strictly, every measured random variable is therefore discrete. Engineers still use continuous models because the codes are so closely spaced that a density describes them well; HW302 (F1-64) explains sampling and the code range of an analog-to-digital converter. D2D3

Two hardware facts shape real distributions. First, a converter has a smallest and a largest code; a quantity outside its range is reported as the end code, so readings pile up there (saturation, also called clipping). Second, the step between codes rounds every reading; F0-62 measures that rounding as quantisation noise. The forensic lab uses a 10-bit reading (codes 0 to 1023) as an exercise; the bit width of a real converter comes from its datasheet. D2W1

Inside the program, a histogram is an array of counters in memory. Filling it is one division (or a multiplication by 1/width), one conversion to an integer index, one bounds decision and one increment per value. The bounds decision is where bugs live: an index computed one too large either writes outside the array (a memory error that AddressSanitizer reports) or, as in the forensic program, is silently skipped. D3

Worked example

Mei's four cousins toss fair coins; X is the number of heads.

  1. PMF. 16 equally likely outcomes; the counts for X = 0, 1, 2, 3, 4 are C(4, k) = 1, 4, 6, 4, 1. So P(X = 2) = 6/16 = 0.375.
  2. CDF. Running totals: 1/16, 5/16, 11/16, 15/16, 16/16.
  3. At least three helpers. P(X ≥ 3) = p(3) + p(4) = 5/16 = 0.3125, or 1 − F(2) = 1 − 11/16, the complement rule.
  4. Between one and three helpers. P(1 ≤ X ≤ 3) = F(3) − F(0) = 15/16 − 1/16 = 0.875.
  5. A biased coin. Suppose each cousin's coin shows heads with probability 0.3 (an exercise value). Then P(X = 2) = C(4, 2) × 0.32 × 0.72 = 6 × 0.09 × 0.49 = 0.2646. Same formula, different p.
  6. A continuous case. The washing machine finishes at T, uniform on [0, 20] minutes. Density 0.05 per minute; P(T < 5) = 0.25; P(8 < T < 14) = 0.3.

Where the analogy breaks


    

  • Mei's scoreboard is data; a distribution is a model. Two months of bars are one sample of evenings. The distribution is what the bars would look like after infinitely many evenings with the same coins. Treating a small histogram as the true distribution over-reads its bumps (run R1's edge values 3 and 8 instead of about 10). D1R1
    • 

  • Bars have heights; densities have areas. On the scoreboard, a taller bar means more evenings. For a continuous variable, the height of a density is not a probability, and it can be above 1. Only areas are probabilities. D1
    • 

  • Not every number on the scoreboard is a random variable of the same experiment. If the family changes the rule (five cousins instead of four), the evenings no longer share one distribution. Real logs mix conditions in the same way (a sensor in shade and in sun), which a single histogram blurs together.
    •

Expected observations


The real tally has the same shape as the PMF (highest at 2, lowest at 0 and 4) but not the same counts: with 48 trials, differences of several counts are ordinary, as the simulated 10,000-experiment run R1 shows at its rare edges. With integer data, bin edges at half-integers avoid values sitting exactly on an edge.


Verification

Troubleshooting


    

  • A count is one value short → the maximum fell on the right edge of the last bin → clamp it into the last bin.

  • AddressSanitizer error "heap-buffer-overflow" → index out of range → check the index before incrementing, and print the value that caused it.

Summary


    

  • A random variable is a number attached to each outcome; statements about it are events.
    • 

  • Discrete variables have a PMF (probabilities that add up to 1); continuous variables have a PDF (areas are probabilities; single values have probability 0).
    • 

  • The CDF F(x) = P(X ≤ x) describes any random variable; P(a < X ≤ b) = F(b) − F(a).
    • 

  • Bernoulli: one yes/no trial. Binomial(n, p): number of successes in n independent identical trials, P(X = k) = C(n, k) pk(1 − p)n − k. Uniform: equal probability (or equal density) over a range.
    • 

  • A histogram estimates a distribution; its counts must add up to N, and its bins must cover the minimum and the maximum.
    • 

  • Sensors and converters have end codes; readings that pile up there (saturation) are part of the distribution and must not be dropped.
    •
