Story hook

Analogy

Zainab is making pancakes for a family gathering. Her recipe card says: "one batch: 2 eggs, 150 g flour". But how many batches? That depends on how many guests come, and nobody knows yet.

So she writes a note on the fridge: "eggs = 2 × batches". Whatever the number of batches turns out to be, the note tells her the eggs. She sticks a label on an empty jar: "batches". When her aunt phones to say three batches, Zainab drops three counters into the jar. Now the note gives 2 × 3 = 6 eggs.

Her cousin Leo has a different job: seats. There are 3 tables with 4 chairs each. Every guest gets a ticket number. Leo wants a rule, so that he can work out any ticket without counting the whole room.

A rule that works for any number, written with a name instead of the number, is what algebra is about. This chapter starts it.

What you will be able to do

  • Use a letter or a name to stand for a number, and explain what it means in a story.
  • Write an expression from a word description, such as "3 packs and a 5-coin bag" → 3p + 5.
  • Substitute a number into an expression and work it out with the right order of operations.
  • Simplify expressions by collecting like terms and expanding simple brackets.
  • Apply the seat-ticket formula ticket = table × seatsPerTable + seat, and work it backwards.
Jargon box
Variable (maths)
Simple words: a letter or name that stands for a number. Analogy: a labelled jar: the label is the name, the counters inside are the number. Precise: a symbol such as n or batches that represents a number, either one not yet known or any number from a range. Not the same as a variable in a program (KID102 chapter F0-30), which is a named storage place whose contents can change. D1 §2.1
Expression
Simple words: a recipe for a number, made of numbers, letters and operations, with no equals sign. Analogy: the note "2 × batches" before you know the batches. Precise: a combination of numbers, variables and operations, such as 3n + 2, that has a value once every variable has a value. D1 §2.1
Substitute
Simple words: put a number in place of a letter. Analogy: dropping counters into the jar. Precise: replace each occurrence of a variable by a given value (in brackets if needed) and evaluate with the order of operations. D1 §2.2
Term
Simple words: one piece of an expression that is added or taken away. Analogy: one line of the recipe. Precise: a product of a number (its coefficient) and variables, such as 3n; in 3n + 2 the terms are 3n and 2. D1 §2.2
Like terms
Simple words: terms with exactly the same letters, which can be added together. Analogy: 4 cups of rice and 3 cups of rice make 7 cups of rice; cups of rice and cups of milk do not combine. Precise: terms whose variable parts are identical; 4a + 3a = 7a, but 3a + 2b cannot be combined. D1 §2.2
Formula
Simple words: a rule that says how to work out one quantity from others. Analogy: the fridge note "eggs = 2 × batches". Precise: an equation that gives one variable in terms of others, such as ticket = table × seatsPerTable + seat. D1 §2.1

Layer 1 — the kid explanation

A variable is a name for a number. Think of a jar with a label. The label might say "batches" or only "n". The jar holds a number of counters. You can talk about the jar before you know what is inside it.

An expression is a recipe that uses variables. "2 × batches" is an expression. So is "3n + 2". On its own it is not a number yet. It becomes a number when you know what is in the jar.

Mathematicians are lazy writers. Instead of 2 × n they write 2n. The number goes first and the × is left out. So 3n means "3 times n", never "thirty-something".

Putting numbers in: substituting

To find the value of an expression, put the number in place of the letter. This is called substituting. Then work it out with the order of operations from F0-12.

Try 3n + 2 when n = 5. Replace n: 3 × 5 + 2. Multiply first: 15. Then add: 17. If n changes to 1, the same expression gives 3 × 1 + 2 = 5. One recipe, many answers.

With a negative number, use brackets. If n = −2, then 3n = 3 × (−2) = −6. Without brackets you might write 3 − 2, which is a different sum.

Turning words into expressions

A pack of biscuits costs p coins. You buy 3 packs and a bag that costs 5 coins. The cost is 3p + 5. If a pack costs 4 coins, the cost is 3 × 4 + 5 = 17 coins.

Each piece joined by + or − is a term. In 3p + 5 the terms are 3p and 5. Terms with the same letter are like terms, and you can add them. 4a + 3a = 7a, in the same way as 4 cups of rice and 3 cups of rice make 7 cups. But 3a + 2b stays as it is. Cups of rice and cups of milk do not combine.

Brackets

What is 2(n + 3)? The brackets say: add first, then double. It means "two lots of (n + 3)". That is n + 3 + n + 3, which is 2n + 6. Multiply everything inside the brackets.

A common slip is to write 2n + 3. Test it with n = 4. The right answer is 2 × 7 = 14. The slip gives 2 × 4 + 3 = 11. Testing with a small number catches it.

Leo's seat tickets

Leo has tables with 4 seats each. He numbers tables from 0 and seats from 0. Table 0 gets tickets 0, 1, 2, 3. Table 1 starts where table 0 stopped: 4, 5, 6, 7. Table 2 gets 8 to 11.

So each table starts at table × 4. Then you add the seat number. The formula is: ticket = table × seatsPerTable + seat. For table 2, seat 3: 2 × 4 + 3 = 11. Figure 2 shows it.

Why start at 0? Because then table 0 starts at 0 × 4 = 0, and nothing is skipped. Every seat gets a different ticket, and the tickets run 0, 1, 2, … with no gaps. Keep this formula. It is the most important one in this course.

Layer 2 — the student explanation

An expression is built from numbers, variables and operations. A term is a product of a number, called the coefficient, and variables: in 3n the coefficient is 3. Like terms have identical variable parts and combine by adding coefficients: 5b − 2b + 1 = 3b + 1. Check it with b = 3: 15 − 6 + 1 = 10 and 9 + 1 = 10. D1 §2.2R2

Multiplication spreads over addition: a(b + c) = ab + ac. So 2(n + 3) = 2n + 6, and the perimeter of a rectangle, l + w + l + w, is 2l + 2w = 2(l + w). For a rug 7 by 3, the perimeter is 2 × 7 + 2 × 3 = 20. D1 §7.3R2

The seat formula works backwards too. Given a ticket, the table is the quotient of ticket ÷ seatsPerTable and the seat is the remainder (F0-12). Ticket 14 with 4 seats per table: 14 ÷ 4 = 3 remainder 2, so table 3, seat 2. Check: 3 × 4 + 2 = 14. Because the seat is always smaller than seatsPerTable, each ticket comes from exactly one (table, seat) pair: no repeats and no gaps. D1 §1.5R2

Layer 3 — the engineer's depth

Note

For the curious. Nothing here is needed for the quiz.

The seat formula appears, with other names, in this university's GPU courses. There a "table" is a block, "seats per table" is the block size, and a "seat" is a thread's position in its block. The guide writes it as i = blockIdx.x * blockDim.x + threadIdx.x. With 256 seats per table, table 3 seat 10 has ticket 3 × 256 + 10 = 778. U1R2

Maths variables and program variables differ. In maths, n stands for one value throughout a calculation. In a program, a variable is a storage place, and x = x + 1 means "take the value, add 1, store it back": the C++ rules say that = replaces the value stored on its left with the value worked out on its right. As a maths equation, x = x + 1 has no solution. KID102 (F0-30) teaches program variables. D1 §2.1D2 §7.6.19

How the hardware actually does it

In the rules of C++, each variable of a running program is stored in the computer's memory, in bytes that have addresses (F0-15). The compiler turns an expression such as table * seatsPerTable + seat into steps the processor can do. The C++ grammar groups table * seatsPerTable before the +, the same as the order of operations you learned in F0-12, so the multiplication is done first and its result is then added to seat. Run R1 shows the result. D2 §6.7.1, §7.1, §7.6.5R1

Part B — substituting

  1. 3n + 2 with n = 5: 3 × 5 + 2 = 15 + 2 = 17.
  2. 2(n + 3) with n = 4: 2 × (4 + 3) = 2 × 7 = 14. Compare 2n + 3 = 11: different, so they are not the same expression.
  3. 4a + 3a with a = 2: 8 + 6 = 14, and 7a = 14. Same, as collecting like terms promised.

Part C — seat tickets

  1. Table 2, seat 3, 4 seats per table: 2 × 4 + 3 = 11.
  2. Table 0, seat 0: 0 × 4 + 0 = 0, the first ticket.
  3. Table 5, seat 1: 5 × 4 + 1 = 21.
  4. Backwards, ticket 14: 14 ÷ 4 = 3 remainder 2, so table 3, seat 2.
  5. Big tables of 256 seats, table 3, seat 10: 3 × 256 + 10 = 778.

Where the analogy breaks


    

  • A jar can hold anything; a variable holds one kind of thing. You could put buttons and beans in one jar. A maths variable stands for a number, and a program variable has a type and a fixed size (KID102 F0-31).
    • 

  • A real jar is never "unknown". You can always look inside a jar. A maths variable may stand for a number nobody knows yet; F0-17 shows how to find it.
    • 

  • Real tables can have different sizes; the formula cannot. The seat formula only works if every table has the same number of seats. With one table of 5 and one of 3, it gives wrong tickets.
    •

Transition box

Where you came from: F0-12 (the four operations and their order), F0-14 (negative numbers) and F0-15 (powers, written with a letter n as the exponent). What carries over: every arithmetic rule still applies; a letter is only a number you have not filled in yet. What changes: you now write rules that work for every number at once; × is often left out (2n); brackets must be expanded carefully; and a "variable" in maths is a value, not the changeable storage place it is in a program. What comes next: F0-17 asks the reverse question: if 3n + 2 = 14, what is n? Equations as balance scales. D1 §2.1

Lab


Goal


Turn a real home recipe into formulas, and give a group of chairs seat tickets using the formula, then check both with Listing 1.


Hardware and software needed


Any recipe card or recipe from home; paper; up to 12 chairs or cushions (or draw them). Optional: a computer with a C++ compiler; this build used g++ (Ubuntu 13.3.0-6ubuntu2~24.04.1) 13.3.0.


Safety


None beyond normal care at home. Ask before moving furniture; you can draw the chairs instead.


Steps


    

  1. Pick three ingredients from the recipe. For each, write a formula with n = number of batches, such as sugar = 50n.
    2. 

  2. Make a table for n = 1, 2, 3, 4 by substituting.
    3. 

  3. Arrange chairs in rows ("tables") of equal size, for example 3 rows of 4. Number rows and places from 0.
    4. 

  4. Write each chair's ticket with ticket = row × chairsPerRow + place. Put a paper ticket on every chair.
    5. 

  5. Check: are the tickets 0 to 11 with no gaps and no repeats?
    6. 

  6. Optional: in Listing 1, change batches, table, seat and seatsPerTable to match your lab. Predict, run, compare.
    7. 



Expected observations


Each ingredient column grows by the same amount for each extra batch. The chair tickets run from 0 to (rows × chairsPerRow − 1) with no gaps. Listing 1 printed "table 2, seat 3 has ticket 11" in run R1; your own numbers will give your own tickets.


Verification


Pick any ticket and work it backwards: quotient and remainder of ticket ÷ chairsPerRow must give the row and place where that ticket sits.


Troubleshooting


    

  • Two chairs got the same ticket → the formula used the wrong row size → recheck chairsPerRow.
    • 

  • Tickets start at 1 → you numbered rows from 1 → number from 0, or accept that the first row starts at chairsPerRow.
    • 

  • An ingredient total looks too big → substituted without multiplying first (e.g. 50 + n) → write the × sign explicitly.
    • 



Extension


Some recipes have a fixed part, such as "a pinch of salt per pot plus 2 g per batch". Write an expression with two terms for it, like 1 + 2n.

Summary


    

  • A variable is a name for a number, like a labelled jar.
    • 

  • An expression is a recipe made of numbers, variables and operations; 2n means 2 × n.
    • 

  • Substitute a value (in brackets if negative) and use the order of operations.
    • 

  • Like terms combine (4a + 3a = 7a); unlike terms do not.
    • 

  • Multiply every term inside brackets: 2(n + 3) = 2n + 6.
    • 

  • Seat tickets: ticket = table × seatsPerTable + seat, numbering from 0, with no gaps or repeats.
    • 

  • Backwards: table = quotient, seat = remainder of ticket ÷ seatsPerTable.
