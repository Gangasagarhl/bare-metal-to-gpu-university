Story hook

Analogy

Yusuf is helping in the kitchen. He has an egg box, a measuring jug, a light switch, a fridge magnet with one letter, and a long row of magnet letters that spells "SOUP".

His aunt says, "Put three and a half eggs in the egg box." Yusuf laughs. An egg box has places for whole eggs only. Half an egg does not fit. The measuring jug is different. It can hold 1.5 litres of water, no problem.

The light switch can only be on or off. The single magnet shows one letter. The row of magnets can spell a whole word, as long or as short as you like.

Every container is good at one kind of thing. A program's jars are the same. Each one has a shape, called its type, and the shape decides what can go inside. Today you meet the five shapes you will use most.

What you will be able to do

  • Choose the right type for a value: int, double, bool, char or std::string.
  • Predict what C++ prints for whole-number division and remainders, and check it with a run.
  • Explain why 7 / 2 gives 3 but 7.0 / 2 gives 3.5.
  • Read a word and a number from input, join text with + and count its characters.
  • Find a "lost half" bug caused by whole-number division.
Jargon box
Type
Simple words: The kind of value a variable can hold: whole number, decimal, true/false, letter or text. Analogy: The shape of a jar: an egg box holds eggs, a bottle holds liquids. Precise: The property of a variable or value that decides which values it can hold and which operations work on it, for example int, double, bool, char and std::string. R1, D1
int
Simple words: The type for whole numbers, like 7 or -3. Analogy: A jar for whole eggs: no half eggs allowed. Precise: The basic signed integer type; on the build machine it used 4 bytes and its largest value printed as 2147483647 (R3). R1, R3, D1
double
Simple words: The type for numbers with a decimal point, like 1.5. Analogy: A measuring jug that can hold 1.5 litres. Precise: A floating-point type; many decimals, such as 0.1, are stored only approximately, which is why 0.1 + 0.2 printed as 0.30000000000000004 with 17 digits (R2). R1, R2, D1
bool
Simple words: The type for yes/no answers: true or false. Analogy: A light switch: on or off. Precise: The Boolean type with the two values true and false; std::cout prints them as 1 and 0 unless std::boolalpha is used (R1). R1, D1
char
Simple words: The type for one single character, like 'A'. Analogy: One fridge-magnet letter. Precise: A type that holds one character, written in single quotes; the character 'A' printed as the number 65 when converted to int on the build machine (R1). R1, D1
std::string
Simple words: The type for a piece of text, like a name or a sentence. Analogy: A string of fridge-magnet letters in a row. Precise: The standard library type from <string> that holds a sequence of characters; it can be joined with + and knows its length through size() (R1, R4). R1, R4, D1
Integer division
Simple words: Dividing whole numbers in C++ gives a whole number: the part after the point is dropped. Analogy: Sharing 7 eggs between 2 boxes: each box gets 3 whole eggs, and 1 egg is left over. Precise: When both operands of / are integers, the result is an integer and the fractional part is discarded: 7 / 2 printed 3 and 7 % 2 printed the remainder 1 (R2). R2, R5, D1
Remainder operator
Simple words: The % sign: it gives what is left over after a whole-number division. Analogy: The egg that does not fit in the boxes. Precise: The operator % on integers; 7 % 2 printed 1 in this build (R2). R2, D1

Layer 1 — the kid explanation

In F0-30 every jar held whole numbers. But programs need other things too. A recipe needs 1.5 litres of water. A game needs to know "is the door open: yes or no?" A greeting needs a name.

So each jar gets a shape. The shape is called its type. You choose the type when you create the jar, and it never changes.

Whole numbers go in an int. Numbers with a decimal point go in a double. Yes-or-no answers go in a bool. One single letter or sign goes in a char. Words and sentences go in a std::string.

The type matters when you do sums. Share 7 whole eggs between 2 boxes. Each box gets 3 eggs, and 1 egg is left over. C++ does the same with whole numbers: 7 divided by 2 gives 3. If you want 3.5, you must use decimal numbers.

The type also matters when you print. A bool prints as 1 or 0 unless you ask for the words. And a letter is secretly stored as a number. You will see both in the real run.

Layer 2 — the student explanation

An int holds whole numbers, positive or negative. A double holds numbers with a fractional part, such as 1.5. A bool holds true or false. A char holds one character, written in single quotes: 'A'. A std::string holds text in double quotes; you need #include <string> for it. R1, D1

When both numbers in a division are int, the result is an int too. The part after the decimal point is thrown away. So 7 / 2 printed 3. The remainder operator % gives the leftover: 7 % 2 printed 1. If at least one number is a double, the division keeps the fraction: 7.0 / 2 printed 3.5. R2, D1

Printing true showed 1. After std::boolalpha was sent to std::cout, the same value printed as true. Printing the char 'A' showed the letter, but converting it to int with static_cast<int> showed 65. A character is stored as a number code, the idea you met in F0-03. R1, D1

Strings can be joined with + when at least one side is a std::string: "Hello, " + name + "!" works because name is a std::string. The function size() counts the characters: "soup" has 4. R1, R4, D1

Layer 3 — the engineer's depth

Note

For the curious. Each type uses a fixed number of bytes in memory. Listing 3 asked this machine with sizeof: a bool and a char used 1 byte, an int 4 bytes and a double 8 bytes. The biggest int was 2147483647 and the smallest −2147483648. These are measurements on this build machine, not promises for every computer. R3

A double cannot store most decimals exactly, because it stores numbers in binary. 0.1 + 0.2 printed as 0.3 with the normal number of digits, but as 0.30000000000000004 when 17 digits were requested. So never test whether two double values are exactly equal; you will learn the safe way in later courses (MA302). R2, D1

Not verified — check before relying on this

This build measured the sizes of int and double on one machine only. Whether the C++ rules allow other sizes on other kinds of computers was not checked here. Check the C++ standard (ISO/IEC 14882 working draft, the clause on fundamental types), record the answer in the dossier, and until then treat Listing 3's numbers as "measured on this machine".

How the hardware actually does it

Memory stores only bits: rows of switches, as in F0-02. The type tells the program how to read a row of bits. The same bits could mean a number, a letter or true/false; the type decides which. That is why the letter 'A' could be printed as the number 65: same bits, different reading. Whole numbers and decimal numbers are stored in quite different bit patterns, which is one reason C++ keeps their types apart. R1, D2

Worked example

Three friends share 10 biscuits fairly. How many does each get, and how many are left? We predict each line of a tiny calculation, then compare with what Listing 2 showed for the same kind of sum.

  1. With whole numbers: 10 / 3. 3 × 3 = 9, and 3 × 4 = 12 is too many. So each friend gets 3. The fraction is thrown away.
  2. The remainder: 10 % 3. 10 − 9 = 1 biscuit is left.
  3. Check: 3 × 3 + 1 = 10. The share and the remainder always rebuild the starting number.
  4. With a decimal: 10.0 / 3. Now the answer keeps its fraction: 3.333… C++ prints a rounded version of it.

Listing 2 did the same kind of sum with 7 and 2: 7 / 2 printed 3, 7 % 2 printed 1, and 3 × 2 + 1 = 7. With 7.0 / 2 it printed 3.5. R2

Where the analogy breaks


    

  • A real measuring jug can hold any amount, as exactly as you can pour. A double stores many decimals only approximately: 0.1 + 0.2 was not exactly 0.3 (Listing 2). R2
    • 

  • An egg box cannot take half an egg, and you would notice at once. In C++, int cups = 2.9; built without any message and stored 2: the fraction vanished silently. The forensic lab shows how sneaky that is. R5, R6
    • 

  • A magnet letter is only a letter. A char is really a small number with a letter meaning on top: 'A' printed as 65 when read as a number. R1
    • 

  • An egg box has as many places as you can see. An int has a hidden limit: on this machine nothing above 2147483647 fits. R3

Forensic lab answer key


    

  • Observation: 3 slices and 2 friends, but "Each friend gets 1 slices". A person expects 1.5. R5
    • 

  • Hypotheses: (a) the double cannot hold 1.5; (b) the division itself already lost the fraction. Hypothesis (a) is ruled out: Listing 1 printed a double holding 1.5 correctly.
    • 

  • Root cause: line 7 divides two int values, so slices / friends is worked out as whole-number division, giving 1. Only then is 1 stored in the double. The type on the left cannot bring back the lost half.

  • Fix: double each = static_cast<double>(slices) / friends; The fixed program pizza_fixed.cpp printed "Each friend gets 1.5 slices" in this build. R5
    • 

  • Why no warning: whole-number division is legal and often wanted (Listing 2 used it on purpose); the flags used by this course did not warn about it.
    • 

  • Prevention: for every /, ask "are both sides whole numbers, and is that what I want?"; test with numbers that do not divide evenly.
