Story hook

Analogy

Ana and her cousin Felix each bake cookies for a school sale. Ana packs them in boxes of 1000. Felix packs them in boxes of 1024, because he likes doubling: 2, 4, 8, … all the way to 1024.

At the sale, both cousins write "1 thousand-box" on their labels. A customer buys one box from each and counts. "These boxes are different!" she says. "One has 24 more cookies."

Ana and Felix were both honest. They used the same word for two different sizes. Computers have exactly this problem with the word "kilo". In this chapter you will learn the names for groups of bits, and how to label sizes so nobody is confused.

What you will be able to do

  • Explain what a byte is, and show one byte as a row of eight switches.
  • Explain what a word is, and why its size depends on the machine.
  • Convert sizes with decimal prefixes (kB, MB, GB: powers of 1000) and binary prefixes (KiB, MiB, GiB: powers of 1024).
  • Tell bits (b) from bytes (B), and convert between them.
  • Diagnose a size report that uses the wrong unit name (the forensic lab).
Jargon box
Byte
Simple words: a group of eight bits. Analogy: one row of eight hallway switches, each worth double the one to its right. Precise: a group of 8 bits that holds one of 256 patterns (0 to 255 when read as an unsigned number); the unit symbol is B. The C++ constant CHAR_BIT printed 8 in our run. W1 R1
Word
Simple words: the size of number a computer likes to work with in one go. Analogy: how many rows of switches the house's control panel flips at once. Precise: a machine-dependent group of bytes that a processor handles as one unit; its size is set by the processor's architecture manual, not by a universal rule. D1
Kilobyte (kB)
Simple words: one thousand bytes. Analogy: Ana's box of 1000 cookies. Precise: 1 kB = 1000 B, using the decimal (SI) prefix kilo = 103; MB = 10002 B, GB = 10003 B. W1 D2
Kibibyte (KiB)
Simple words: 1024 bytes. Analogy: Felix's box of 1024 cookies. Precise: 1 KiB = 210 B = 1024 B, using the binary prefix kibi; MiB = 10242 B, GiB = 10243 B. W1 D3
Bit and byte symbols (b, B)
Simple words: small b means bits, capital B means bytes. Analogy: one switch versus one whole row. Precise: 1 B = 8 b; this university spells out "Gbit/s" and "GB/s" at levels L0–L2 so the two cannot be mixed up (guide 13.3). W1

Layer 1 — the kid explanation

One switch is a bit. A row of eight switches is a byte. A byte can show 256 different patterns, from 00000000 to 11111111. That is enough for a small number, or for one letter of the alphabet.

Computers handle bytes in bigger bundles too. A word is the bundle size a particular computer likes best. Different computers like different sizes, so always ask "a word on which machine?"

Files and memory hold many bytes, so we use bigger units. Here is the tricky part. In everyday life, "kilo" means 1000: a kilometre is 1000 metres. But in binary, round numbers are powers of two. The power of two nearest to 1000 is 1024.

So people made two sets of names. kB (kilobyte) means 1000 bytes, like Ana's box. KiB (kibibyte, said "kibby-byte") means 1024 bytes, like Felix's box. The little "i" means "the binary one". Use the right name, and nobody gets confused.

Layer 2 — the student explanation

A byte is 8 bits; it is written B. A bit is written b. So a speed in "Mbit/s" and a size in "MB" differ by a factor of 8 before you even think about prefixes. Our run printed CHAR_BIT, the number of bits in the smallest C++ unit of storage, as 8. W1 R1

Decimal prefixes multiply by 1000 each step: kilo (k) = 1000, mega (M) = 1000 × 1000, giga (G) = 1000 × 1000 × 1000. Binary prefixes multiply by 1024 = 210 each step: kibi (Ki), mebi (Mi), gibi (Gi). The run of Listing 1 prints all six values. W1 R1

This university follows one rule (guide 13.3): binary prefixes for memory sizes where the quantity is binary; decimal prefixes only where the source document uses decimal units, and then it says so. A size without a clear unit is a bug waiting to happen.

A word has no single size. Its size is set by each processor's own manual. Our program cannot print "the word size" directly, but it printed two related sizes on the machine that ran it: an int took 4 bytes and a pointer (a memory address) took 8 bytes. Your machine may print different numbers: run the listing and write yours down. R1 D1

Not verified — check before relying on this

The names kibi, mebi and gibi (Ki, Mi, Gi) and the definition of kilo, mega and giga as powers of 1000 come from standards that this build could not open: the binary prefixes from IEC 80000-13 (title only), and the decimal prefixes from "The International System of Units (SI)", the SI Brochure published by the BIPM (title only). The arithmetic in this chapter (1024 = 210, 1000 = 103) is true by definition; the naming convention is tagged to these standards pending verification by the Source Researcher (dossier gate G1 open).

Layer 3 — the engineer's depth

Note

For the curious. The word "word" is especially slippery. Some processor manuals keep an old meaning (a fixed small size) even on machines whose registers are much wider, and then use names like "double word" and "quad word" for bigger units. Always read the size from the manual of the exact processor family, and in C++ prefer types whose size is in their name, such as std::uint8_t, std::uint32_t and std::uint64_t, which F0-24 and F0-25 use. D1 D4

Not verified — check before relying on this

That a specific processor family's manual uses "word" for a size smaller than its register width is a claim about that manual. Check the processor vendor's architecture manual (for example the software developer's manual of the processor family recorded in the dossier) before giving any specific size.

How the hardware actually does it

Memory is organised as a long list of numbered places. In the computers this university studies, each number (an address) picks out one byte. The processor moves several bytes together when it loads a word. How many bytes, and how memory chips are counted, comes from the product's own documentation; that is the subject of HW102 and later hardware courses. This chapter does not quote any real product's sizes. D1

Worked example

How big is a file of 5,000,000 bytes?

  1. In MB: 5,000,000 ÷ 1,000,000 = 5 MB exactly.
  2. In MiB: 1 MiB = 1024 × 1024 = 1,048,576 B. 5,000,000 ÷ 1,048,576 ≈ 4.77 MiB.
  3. In bits: 5,000,000 × 8 = 40,000,000 bits.

The run of Listing 1 prints 5 MB, 4.76837 MiB and 40000000 bits. W1 R1

How much bigger is each binary unit?

  1. KiB versus kB: 1024 − 1000 = 24; 24 ÷ 1000 = 0.024 = 2.4 %.
  2. MiB versus MB: 1,048,576 − 1,000,000 = 48,576; ÷ 1,000,000 = 0.048576 ≈ 4.9 %.
  3. GiB versus GB: 1,073,741,824 − 1,000,000,000 = 73,741,824; ÷ 1,000,000,000 ≈ 7.4 %.

Each step multiplies by 1024 instead of 1000, so the extra 2.4 % is multiplied again at every step. W1

How many bytes in 3 KiB? In 3 kB?

3 × 1024 = 3072 B. 3 × 1000 = 3000 B. A label that says only "3K" could mean either. W1

Where the analogy breaks


    

  • Cookie boxes can be any size; computer units are fixed by definition. Ana could pack 999 cookies if she liked. A kB is exactly 1000 B and a KiB exactly 1024 B, always. W1
    • 

  • A row of eight switches looks like a number, but a byte is not always a number. The same byte can be a letter, part of a colour (F0-22) or part of a bigger number. The program decides. D4
    • 

  • A "word" has no fixed size in the house. The analogy of "how many rows the control panel flips at once" hides that every processor family chooses its own size, and that manuals do not even agree on what to call it (see Layer 3). D1

Forensic lab answer key


Observation: the byte count is the same for both reports: 3,145,728. Report A says 3.14573 MB; Report B says 3 MB. Hypotheses: (1) one program computes wrongly; (2) both compute correctly but one uses the wrong unit name. Evidence: 3,145,728 ÷ 1,000,000 = 3.145728, so Report A is right: it is about 3.15 MB. 3,145,728 ÷ 1,048,576 = 3 exactly (3,145,728 = 3 × 1024 × 1024), so Report B's arithmetic is right too, but the answer is in MiB. Neither program is "broken" in its arithmetic; hypothesis 2. Root cause: Listing 2, line 11 labels a 1024 × 1024 division as "MB". Fix: change the label to "MiB".
