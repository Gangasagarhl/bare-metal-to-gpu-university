Story hook

Analogy

Kwame's family has a big cupboard with a light inside. The light has two switches. One is on the wall, and one is a little button inside the door frame that is pressed only when the door is open. The light comes on only when the wall switch is on and the door is open.

At the stairs it is different. There is one switch at the bottom and one at the top. Kwame can turn the light on downstairs and off again upstairs. His cousin Sofia wonders: "How does the light know which switch I used?"

Both puzzles have the same answer. A light that depends on two switches follows a rule, and the rule can be written as a small table. In this chapter you will write those tables, called truth tables, and test them with a tiny circuit model.

What you will be able to do

  • Write the truth tables of AND, OR, NOT and XOR from memory.
  • Explain AND and OR with two light switches in a row (series) and side by side (parallel).
  • Explain XOR with the two switches of a stair light.
  • Build a truth table for a new rule by listing every combination of inputs.
  • Diagnose a stair-light model that uses the wrong rule (the forensic lab).
Safety

The light circuits in this chapter are models only: drawings and a small C++ program. Never open a wall switch, a lamp holder or a socket. House lights run on mains electricity, which can kill, and this university does no mains work at any level. Real circuits with switches and lamps are built later, in KID103, with battery kits designed for children and an adult present (see the safety rules).

Jargon box
Boolean value
Simple words: a value that is either true or false. Analogy: a switch is on or off; a lamp is lit or dark. Precise: a value of a two-element set {false, true}, written 0 and 1; in C++ the type bool, which prints as 0 or 1 by default (run R1). R1 D4 §1.1.1 D3 §6.8.1
Truth table
Simple words: a table that lists every possible input and the output for each. Analogy: a chart by the cupboard that says, for each position of the two switches, whether the light is on. Precise: a complete listing of a Boolean function: one row for each of the 2n combinations of its n inputs, with the output value. W1
AND
Simple words: true only when both inputs are true. Analogy: two switches one after the other in the same wire (in series). Precise: the Boolean function with output 1 exactly when all inputs are 1; in C++, && for bool values and & bit by bit (F0-25). W1 R1
OR
Simple words: true when at least one input is true. Analogy: two switches side by side (in parallel): either one can light the lamp. Precise: the Boolean function with output 1 when one or more inputs are 1; in C++, || and bitwise |. It is "inclusive": both on also gives 1. W1 R1
NOT
Simple words: turns true into false and false into true. Analogy: a push button that breaks the circuit while you press it. Precise: the one-input Boolean function with output equal to the opposite of the input; in C++, ! and bitwise ~. W1 R1
XOR (exclusive OR)
Simple words: true when the two inputs are different. Analogy: the stair light: flipping either switch changes the lamp. Precise: the two-input Boolean function with output 1 exactly when the inputs differ; for bool values in C++, a != b, and bitwise ^. W1 R1

The idea in pictures

Figure 1 shows two circuits drawn as blocks. On the left, switches A and B are in series: the current must pass through both. On the right, they are in parallel: either path will do. Under each is its truth table.

Layer 1 — the kid explanation

Think of the cupboard light. Current must flow through the wall switch and then through the door button. If either one is open, the path is broken. So the light is on only when both are on. That rule is called AND.

Now imagine a lamp with two switches side by side, like two doors into the same room. The current can go through either one. If at least one is closed, the lamp lights. That rule is called OR.

A push button that breaks the circuit while you press it does the opposite of your finger. Pressed means dark. Not pressed means lit. That rule is called NOT.

The stair light is the cleverest. Flipping either switch changes the lamp. If both switches are the same, the lamp is off. If they are different, it is on. That rule is called XOR, short for "exclusive OR": one or the other, but not both.

A truth table writes such a rule down completely. With two switches there are four combinations: off-off, off-on, on-off, on-on. The table has one row for each. Nothing is left out, so nothing is left to guess.

Layer 2 — the student explanation

A Boolean value is either false (0) or true (1). A logic rule takes Boolean inputs and gives a Boolean output. A truth table lists all 2n input combinations for n inputs, in counting order: 00, 01, 10, 11 for two inputs, the binary numbers 0 to 3 (F0-20). W1

NOT has one input: NOT 0 = 1 and NOT 1 = 0. These four tables match the output of Listing 1. R1

Some facts you can read straight from the tables. AND is 1 in only one row; OR is 0 in only one row. OR and XOR differ only in the last row, where both inputs are 1. XOR is 1 exactly when the inputs differ, so for two Boolean values it is the same as "not equal". W1

In C++, the logical operators on bool values are && (AND), || (OR) and ! (NOT); Listing 1 writes XOR as a != b. On whole bytes, the bitwise operators of F0-25 apply the same tables to each pair of bits. R1 D3 §7.6.2.1, §7.6.14, §7.6.15

To build a truth table for any new rule: list the inputs in counting order, then work out the output for each row. Example: "the porch lamp is on if it is dark AND (someone is at the door OR the alarm is set)" has three inputs, so 2 × 2 × 2 = 8 rows. W1

Layer 3 — the engineer's depth

Note

For the curious. With two inputs there are 4 rows, and each row's output can be 0 or 1, so there are 24 = 16 different two-input rules. AND, OR and XOR are three of them; NAND (NOT AND) and NOR (NOT OR) are two more. NAND is special: AND, OR and NOT can all be built from NAND alone, and from those three you can build every other rule. HW102 builds all the gates from NAND. In C++, && and || also "short-circuit": if the left side already decides the answer, the right side is not evaluated; that matters when the right side has an effect, and is taught with conditions in KID102. W1 D4 §1.1.1 D3 §7.6.14, §7.6.15

How the hardware actually does it

Inside a chip, the switches are tiny electronic switches (transistors), and small groups of them form gates that compute AND, OR, NOT and XOR on electrical signals. The idea is the same as Figure 1: arrangements of switches decide whether a signal gets through. The gates themselves are the first topic of HW102. D1 ch. 6 D4 §1.1.2

Where the analogy breaks


    

  • Real switches can bounce, stick or be half pressed; a Boolean value cannot. The model's inputs are always exactly true or false. Turning a real, noisy switch into a clean 0 or 1 is an engineering job of its own (later, in hardware courses).
    • 

  • Our stair model chooses "same means off" by definition. If "both the same" meant on instead, the rule would be NOT XOR; flipping one switch would still change the lamp. A real stair light is a wired circuit, and the model says nothing about how it is wired (see the box below). W1
    • 

  • Lamps take time to light; logic in the model is instant. The model prints the result immediately. Real gates take a short time to switch, which matters a lot in HW102 and later courses.
    • 

  • A truth table with many inputs is not practical as a wall chart. Each extra switch doubles the rows. With 10 inputs there are 1024 rows (F0-23); engineers then use algebra instead (F0-27). W1
    •

Transition box

Where you came from: F0-25 used AND, OR, XOR and NOT on the bits of a byte. What carries over: the same four rules; a byte operation is eight truth-table lookups side by side. What changes: you now write each rule completely, as a table with every combination, and connect it to switches in series and parallel. What comes next: F0-27 shows how to rewrite and simplify rules with Boolean algebra, including De Morgan's laws, and how to prove two rules are equal with a truth table. W1

Summary


    

  • A truth table lists every input combination (2n rows) and the output.
    • 

  • AND: 1 only if both are 1 (switches in series).
    • 

  • OR: 1 if at least one is 1 (switches in parallel); it includes the "both" case.
    • 

  • NOT: the opposite (a push-to-break button).
    • 

  • XOR: 1 if the inputs differ (the stair light).
    • 

  • In C++: &&, ||, ! and != for bool; &, |, ~, ^ bit by bit.

Forensic lab answer key


Observation: the lamp did not change on the third line (flip T: 1,1 → lamp stays 1), the fourth (flip B: 0,1 → stays 1) and the last (flip B: 1,1 → stays 1). Evidence table: (0,0) → 0, (1,0) → 1, (0,1) → 1, (1,1) → 1: that is the OR table. Hypotheses: (1) flips are recorded wrongly: ruled out, because each line shows exactly one switch changing, as the flip letter says; (2) the lamp rule is wrong: supported, because the rule's table is OR, while a stair light needs XOR. Root cause: Listing 2, line 8, return bottom || top;. With both switches on, OR still gives 1, so the second switch cannot turn the lamp off. Fix: return bottom != top; (XOR).
