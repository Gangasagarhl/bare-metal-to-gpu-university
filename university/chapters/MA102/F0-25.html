Story hook

Analogy

Zara's family has a little control panel by the front door with eight switches, one for each light in the house. The rightmost is the kitchen. Then the hall, the living room, the bathroom, two bedrooms, the porch, and on the far left, the garden.

At bedtime Zara's grandfather wants to turn off only the bathroom light. He must not touch the other seven. Zara has an idea. She cuts a piece of card with one hole in it, right over the bathroom switch. She lays the card on the panel. Now only one switch can be reached.

That card is a mask. Computers use masks all the time, to change one bit of a byte without disturbing the others. In this chapter you will make masks, and learn to slide bits left and right with shifts.

What you will be able to do

  • Number the bits of a byte from bit 0 (the LSB) to bit 7 (the MSB).
  • Build a mask with a shift, such as 1u << 3, and use it to set, clear, toggle and test one bit.
  • Use a right shift and a mask to pull a field of several bits out of a byte.
  • Decode a made-up 8-bit status byte from a written description of its fields.
  • Diagnose a mask that clears the wrong lights (the forensic lab).
Jargon box
Bit number
Simple words: the name of a bit's position, counted from the right, starting at 0. Analogy: the room number of each switch on Zara's panel: kitchen is 0, garden is 7. Precise: bit k has place value 2k; bit 0 is the least significant bit and bit 7 the most significant bit of a byte. W1
Mask
Simple words: a pattern of bits that picks which bits you want to touch. Analogy: the card with holes over some switches. Precise: a value combined with data by a bitwise operator so that only the bit positions selected by the mask are set, cleared, toggled or kept. W1
Bitwise operator
Simple words: an operation that works on each pair of bits separately. Analogy: doing the same thing to every switch at once, switch by switch. Precise: in C++, & (AND: 1 only if both bits are 1), | (OR: 1 if at least one is 1), ^ (XOR: 1 if they differ) and ~ (NOT: flip every bit). F0-26 gives their full truth tables. R1 D2 §7.6.2.1, §7.6.11
Shift
Simple words: sliding all the bits left or right by some places. Analogy: moving every light's setting a few rooms along the panel; settings that fall off the end are lost, and empty places get "off". Precise: x << n moves the bits of x n places left (multiplying an unsigned value by 2n while it fits); x >> n moves them n places right (dividing an unsigned value by 2n, dropping the remainder). W1 R1 D2 §7.6.7
Flag
Simple words: one bit that answers a yes/no question. Analogy: one light: on means yes. Precise: a single bit in a larger value whose 1 or 0 records whether a condition is true. W1
Bit field
Simple words: a group of neighbouring bits that together hold a small number. Analogy: three switches side by side used as a dial from 0 to 7. Precise: a contiguous range of bits within a value, read by shifting it down to bit 0 and masking off the other bits. W1

Layer 1 — the kid explanation

Each switch on Zara's panel has a number, counted from the right and starting at 0. The kitchen is switch 0. The bathroom is switch 3. The garden is switch 7. These numbers are called bit numbers.

To work on one switch, you make a mask: a row of eight bits with a 1 only where you want to work. To make a mask with a 1 at position 3, start with a single 1 at position 0 and slide it three places left. That slide is a shift.

Now there are three tricks. To turn a light on, use OR with the mask: switches under a 1 come on, the rest stay as they were. To flip a light, use XOR with the mask: switches under a 1 change, the rest stay. To turn a light off, flip the mask first so it has a 0 in that place and 1s everywhere else; then use AND. Under a 1, a switch keeps its state. Under the 0, it goes off.

To test one light, AND it with its mask. If the answer is not zero, that light is on.

Layer 2 — the student explanation

The bitwise operators work on each pair of bits in the same position, independently. For one pair of bits: AND (&) gives 1 only if both are 1; OR (|) gives 1 if at least one is 1; XOR (^) gives 1 if they are different; NOT (~) flips a single bit. F0-26 writes these rules as truth tables. R1 D2 §7.6.11

Four patterns cover almost every job with a single bit k. The mask is 1u << k. R1

JobCodeWhy it works
Set bit k (turn on)x = x | (1u << k)OR with 1 gives 1; OR with 0 keeps the bit.
Clear bit k (turn off)x = x & ~(1u << k)The flipped mask has 0 at k: AND with 0 gives 0; AND with 1 keeps the bit.
Toggle bit k (flip)x = x ^ (1u << k)XOR with 1 flips; XOR with 0 keeps the bit.
Test bit k(x & (1u << k)) != 0Every other bit is cleared; what is left is non-zero only if bit k is 1.

A mask can select several bits at once: 0b1000'0001 selects bits 7 and 0. The 0b prefix writes a number in binary, and the ' is only a separator for your eyes. R1

A shift moves every bit. x << n moves bits n places left and fills the right with 0s, so for an unsigned value that fits, it multiplies by 2n: 1u << 20 printed 1048576 = 220. x >> n moves bits n places right, and bits that fall off the right end are lost, so it divides an unsigned value by 2n and drops the remainder. W1 R1

A bit field is read in two steps: shift it right until its lowest bit is at position 0, then AND with a mask of as many 1s as the field is wide. For bits 6..4: (x >> 4) & 0b111. A single-bit field is a flag. W1 R1

Layer 3 — the engineer's depth

Note

For the curious. In C++, the operands of these operators are first widened to at least int (or unsigned int). So ~(1u << 3) is a full-width unsigned value with many 1s, not an 8-bit one; that is fine for AND, but it is why Listing 1 converts some results back to std::uint8_t before printing them as eight bits. Use unsigned types for bit work: shifting into or out of the sign bit of a signed type is a trap for the next reader. D2 §7.3.6, §7.6.7, §7.6.2.1 In later courses you will meet hardware registers (device registers, page-table entries) whose manuals describe them bit by bit, in the style "bit 7: flag; bits 6..4: field"; the same shifts and masks read them.

Note

What C++ says. A value of a type smaller than int (such as std::uint8_t) is converted to int before arithmetic when int can hold all its values; this is called integral promotion D2 §7.3.6. The operand of ~ and both operands of a shift are promoted this way D2 §7.6.2.1, §7.6.7. A shift by a negative number of places, or by at least the width of the promoted left operand, has undefined behaviour: never do it D2 §7.6.7. Listing 1, built with -std=c++20 and both sanitizers, produced the output shown with no warnings and no sanitizer messages R1.

How the hardware actually does it

A processor has instructions that apply AND, OR and XOR to all the bits of a register in one instruction, and instructions that shift a register's bits. The RISC-V manual, for example, describes AND, OR and XOR as bitwise logical operations, gets NOT as XOR with all ones (XORI rd, rs1, -1), and has the shifts SLL, SRL and SRA. D1 §1.1.4 One mask operation is therefore one instruction for the machine, not eight. How a particular processor encodes these instructions is in its architecture manual; HW102 builds the gates they are made from, and gates are made from tiny switching devices called transistors. D3 §1.1.2

Worked example

Decode a made-up status byte

A pretend robot vacuum describes its status byte like this (we invented it for practice; no real product uses it):

BitsNameMeaning
7DOOR1 = dust door open
6..4SPEEDspeed level 0–7
3LOWBAT1 = battery low
2..0MODE0 = off, 1 = sweep, … 6 = edges, 7 = return home

The byte reads 0b1011'0110 (0xB6).

  1. Write the bits under their numbers: bit 7 = 1, bits 6..4 = 011, bit 3 = 0, bits 2..0 = 110.
  2. DOOR: (x >> 7) & 1 = 1, so the door is open.
  3. SPEED: (x >> 4) & 0b111 = 011 = 3.
  4. LOWBAT: (x >> 3) & 1 = 0, so the battery is fine.
  5. MODE: x & 0b111 = 110 = 6, edges.

The run of Listing 1 prints the same byte, the shift by 4 (00001011), the low four bits (00000110) and "bits 6..4 as a number: 3". W1 R1

Shift arithmetic

0b1011'0110 = 182. Shifting right by 4 divides by 16: 182 ÷ 16 = 11 remainder 6, and indeed 00001011 = 11 while the lost bits 0110 = 6. W1

Where the analogy breaks


    

  • A card with holes only stops you touching switches; a mask does the work. With AND, OR and XOR, the mask is combined with every bit, even the ones you "do not touch"; they stay the same only because the operation leaves them alone under that mask value. Pick the wrong operation and the "covered" switches change too. W1
    • 

  • Lights do not move between rooms; bits move in a shift. Moving every room's setting along the panel makes no sense in a house, but it is exactly what a shift does, and settings that slide off the end are lost forever. R1
    • 

  • A real panel's switches are all the same; bit numbers carry value. Switch 3 is worth 8 and switch 7 is worth 128. Mixing up "bit 3" and "the value 3" is the bug in the forensic lab. R2
    •

Forensic lab answer key


Observation: before 00001011, after 00001000. Bits 1 and 0 (hall, kitchen) went off; bit 3 (bathroom) stayed on, the opposite of the intent. Hypotheses: (1) AND is the wrong operation; (2) the mask has its 0s in the wrong place. Evidence: 3u = 0000 0011, so ~3u ends in 1111 1100: its 0s are at bits 1 and 0. AND clears exactly those, matching the output. AND with a correct mask is the right operation (Listing 1, line 22), so hypothesis 2. Root cause: Listing 2, line 10, uses the value 3 instead of the bit number 3; the mask must be 1u << 3 = 0000 1000. Fix: lights = lights & ~(1u << 3);.
