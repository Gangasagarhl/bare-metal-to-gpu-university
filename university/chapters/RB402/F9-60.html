Story hook

Analogy

Nadia can now ride, and Tomás invents two games for her. In the first she rides slowly along the path with her eyes closed. Her balance sense tells her exactly how the bike leans, so she stays up. But after a while she has no idea where on the path she is: nothing she can feel depends on her position. Her senses cannot see that part of her state.

In the second game Tomás walks between two identical bicycles and holds both handlebars with one long bar, so that every movement of his arms turns both front wheels the same way. If both bikes lean left, he steers left and both straighten. If one leans left and the other right, whatever he does helps one and hurts the other. His one pair of muscles cannot reach that part of the state. This chapter turns both games into tests you can compute: can the inputs reach every state (controllability), and can the sensors tell every state apart (observability)?

What you will be able to do

  • Test controllability and observability with the rank of the controllability and observability matrices, and with the eigenvector (PBH) test.
  • Explain physically which part of a state cannot be moved or seen, using modes such as "the difference of two pole angles".
  • Choose sensors for a robot by checking which states each sensor set makes observable.
  • Measure how controllable a system is, not just whether, with singular values and minimum-energy inputs.
  • Diagnose a design that is controllable on paper but needs impossible forces.
Jargon box
Controllability
Simple words: the inputs can push the machine from any state to any other state in a finite time. Analogy: your muscles can reach every part of your balance and position. Precise: the pair (A, B) is controllable if for every x0, xf and some finite time there is an input taking x(0) = x0 to x(tf) = xf; for linear time-invariant systems this holds exactly when the controllability matrix has rank n. B1
Controllability matrix
Simple words: a table that lists every direction the input can push the state: directly, after one step of the dynamics, after two, and so on. Analogy: where a push on the handlebar takes the bike now, a moment later, and a moment after that. Precise: Wc = [B, AB, A²B, …, An−1B] ∈ ℝn×nm. B1D1
Observability (control)
Simple words: by watching the sensors for a while (and knowing the inputs) you can work out the whole state. Analogy: from what your senses feel you can tell your lean, its rate, your speed and where you are. Precise: the pair (A, C) is observable if the output y on a finite interval, with u known, determines x(0) uniquely; for LTI systems, exactly when the observability matrix has rank n. Not the same as observability in distributed systems (DS402), which means being able to understand a running service from its logs, metrics and traces. B1
Observability matrix
Simple words: a table of what the sensors see of the state now, and of how it changes over the next steps. Analogy: what your senses report now, and a moment later. Precise: Wo = [C; CA; CA²; …; CAn−1] ∈ ℝnp×n. B1D1
Mode (of a linear system)
Simple words: one of the basic motions a system can make on its own, each with its own rate. Analogy: "falling over", "rolling along", "two bikes leaning apart". Precise: a solution eλtv of x′ = Ax with Av = λv; a mode is uncontrollable if no input can excite or cancel it, unobservable if it leaves no trace in y. B1D1
PBH test (Popov–Belevitch–Hautus)
Simple words: a test that checks each mode separately: can the input touch this one? Analogy: testing each wobble of the bike: can the handlebar affect this wobble at all? Precise: (A, B) is controllable if and only if rank [λI − A, B] = n for every eigenvalue λ of A; dually, (A, C) is observable if and only if rank [λI − A; C] = n for every λ. B1
Stabilisable and detectable
Simple words: the parts you cannot reach (or cannot see) at least settle down by themselves. Analogy: you cannot reach a wobble, but it dies out on its own, so you do not need to. Precise: (A, B) is stabilisable if every uncontrollable mode has Re λ < 0 (|z| < 1 in discrete time); (A, C) is detectable if every unobservable mode does. These are the weakest conditions under which a state-feedback controller, respectively an observer, can be made stable. B1
Minimum-energy input (reachability Gramian)
Simple words: the gentlest input that still gets the state where you want it; how big it is tells you how hard that move is. Analogy: the smallest effort with which you could bring two bikes into a chosen lean. Precise: for x[N] = R u with R = [AdN−1Bd, …, Bd], the input of least Σu² reaching xf is u = Rᵀ(RRᵀ)−1xf; RRᵀ is the N-step reachability Gramian, and its small eigenvalues mark directions that are expensive to reach. B1D1

Layer 1 — the kid explanation

Before you build a controller, ask two questions. First: can my muscles reach everything I care about? A single bar holding two identical bicycles cannot make them lean in opposite ways. Second: can my senses tell me everything I need? With your eyes closed, your balance sense tells you your lean but not where you are.

If the answer to the first question is no, no clever program can fix it: you need another muscle. If the answer to the second is no, you need another sense. Engineers have a test for each that a computer can do in a moment. They also ask a third, trickier question: even if I can reach it, how hard must I push? Sometimes the answer is "harder than any motor can".

Layer 2 — the student explanation

The controllability test

Take the sampled model x[k+1] = Adx[k] + Bdu[k] from rest. After n steps, x[n] = Adn−1Bdu[0] + … + AdBdu[n−2] + Bdu[n−1]: every reachable state is a combination of the columns Bd, AdBd, …, Adn−1Bd. If those columns span ℝn, every state is reachable in n steps. Further steps add nothing new: by the Cayley–Hamilton theorem An is a combination of I, A, …, An−1. The same argument for the continuous model gives the test rank [B, AB, …, An−1B] = n. B1D1

For the cart-pole (Listing 1) the 4×4 matrix Wc has rank 4: one force on the cart can, in principle, take the cart and pole to any position, velocity, angle and angular rate near upright. That is the good news that makes balancing possible at all. Its singular values (50.3, 44.5, 0.863, 0.798) say more, and Layer 3 explains how to read them. R1

The observability test

With no input, y[k] = C Adk x[0]. Stacking n samples gives [y[0]; …; y[n−1]] = Wo x[0] with Wo = [C; CAd; …; CAdn−1]. The initial state can be solved for uniquely exactly when Wo has rank n. With inputs, their known effect is subtracted first, so the test is the same. In continuous time: rank [C; CA; …; CAn−1] = n. B1D1

Two poles on one cart

Put a second pole, length l2 and mass m2, on the cart beside the first. Each pole obeys liθi″ = g θi − x″ (the second equation of F9-59, one per pole), and the cart obeys M x″ = F − b v − m1g θ1 − m2g θ2. With the state (x, v, θ1, ω1, θ2, ω2) this gives the 6×6 model in Listing 2. D1

Now take equal lengths l1 = l2 = l and subtract the two pole equations. The x″ terms cancel and the difference δ = θ1 − θ2 obeys

δ″ = (g / l) δ

with no F in it at all. This is the difference mode of Figure 2, with eigenvalues ±√(g/l) = ±4.4294 1/s for l = 0.5 m. It is uncontrollable, and since one of its eigenvalues is positive it is unstable too: the system is not even stabilisable. No controller of any kind, with any amount of force, can balance two identical poles on one cart. Run R3 confirms rank Wc = 4 of 6 and lists the eigenvalues 5.2269, 4.4294, 0, −0.0714, −4.4294, −5.2555. D1R3

With different lengths the difference is no longer free of F (each pole feels the cart's acceleration divided by its own length), and the rank is 6. But Figure 3 shows the catch: leaning the poles apart by ±0.05 rad in 1 s needs a peak force of 159 N with l2 = 0.25 m, 1,660 N with 0.45 m and 96,100 N with 0.499 m. Controllable is a yes-or-no answer to a question about exact arithmetic; engineering needs to know how much. R2

Layer 3 — the engineer's depth

Testing one mode at a time: PBH

If v is a left eigenvector of A (vᵀA = λvᵀ) with vᵀB = 0, then for any input d(vᵀx)/dt = λ vᵀx: the combination vᵀx evolves on its own, untouched by u. That mode is uncontrollable. The PBH test turns this into a rank condition: (A, B) is controllable exactly when [λI − A, B] has rank n at every eigenvalue λ. It names the culprit, which the controllability matrix does not. Run R3 applies it to the two equal poles: rank 5 at s = +4.4294 and at s = −4.4294 (the difference mode's eigenvalues), rank 6 at a value that is not an eigenvalue. The dual test, rank [λI − A; C] = n, finds unobservable modes. B1R3

The Kalman decomposition and the transfer function

Any linear system can be put, by a change of coordinates, into the four parts of Figure 1. The transfer function G(s) = C(sI − A)−1B + D depends only on the controllable and observable part; every other eigenvalue cancels between numerator and denominator. For the cart-pole with only θ measured, the pole at s = 0 (cart position) does not appear in θ(s)/F(s): the transfer function has order 3, not 4. A state-space model with no uncontrollable and no unobservable part is called minimal; its dimension is the order of G. This is why designing from a transfer function can hide a problem: an unstable, unobservable mode is invisible in G but still grows in the robot. B1D1

Duality

Wo for (A, C) is the transpose of Wc for (Aᵀ, Cᵀ). So (A, C) is observable exactly when (Aᵀ, Cᵀ) is controllable. Listing 1 uses this: obsv is one line that calls ctrb on the transposes. F9-63 uses the same trick to design observers with the pole-placement and LQR code of F9-61 and F9-62. B1D1

How controllable? Gramians and minimum energy

The rank test is a question about exact arithmetic; computers and motors are not exact. Two better questions are: which directions are cheap to reach, and which are expensive? Over N samples, x[N] = R u with R = [AdN−1Bd, …, Bd] (n × N). Among all inputs reaching xf, the one with least Σu[k]² is u = Rᵀ(RRᵀ)−1xf, and its energy is xfᵀ(RRᵀ)−1xf. The matrix RRᵀ is the N-step reachability Gramian. Its eigenvectors with small eigenvalues are expensive directions; a zero eigenvalue is an unreachable one. The continuous-time version is W(t) = ∫0t eAτBBᵀeAᵀτdτ. B1D1

Listing 2 computes the minimum-energy input for the two-pole rig. The peak force grows roughly like 1/(l1 − l2) as the lengths approach each other: 9,380 N at a 1 cm difference, 96,100 N at 1 mm (ten times smaller difference, ten times the force), and at 0 the Gramian becomes singular and inv reports it. A real rig with a 20 N motor would be "controllable" for every l2 ≠ l1 and useless for most of them. R2

Numerical rank, tolerances and units

Rounding makes an exactly rank-deficient matrix look full rank, with a tiny last pivot or singular value. Listing 1's rank counts pivots larger than 10−9 times the largest entry. The singular values printed beside it are a better guide: the angle-only Wo has 23.8, 23.4, 0.00852 and 0, so one direction is invisible and another is barely visible. "Barely" depends on units. Measure the cart in millimetres instead of metres and the columns of Wo for x and v shrink by a factor of 1,000; the singular values change although the physics did not. Before comparing singular values, scale each state by the size that matters for your task (for example the largest acceptable value) and each input by its limit. F9-62 does the same scaling for LQR weights. R1D1U1

How the hardware actually does it

On a real rig, observability is a question of which sensors you buy and where you put them; controllability is a question of which actuators you have and how strong they are. One common arrangement for a cart-pole, used as the example here, is an encoder on the motor or belt (cart position) and an encoder on the pole's hinge (angle); Listing 1 shows that this pair makes every state observable and well conditioned. Velocities are not measured; F9-63 estimates them. Controllability on hardware is bounded by the motor driver's current limit, the belt's grip and the track length: a direction of the state that needs 900 N is unreachable for a 20 N drive, whatever the rank says. R1U1

Not verified — check before relying on this

Untested on hardware. No rig was used in this build. The 20 N limit in the forensic lab is an exercise value. A real drive's force limit follows from its motor's torque constant, the driver's current limit and the pulley radius, taken from the datasheets of the parts in your kit (recorded in the dossier), and should be confirmed by a measurement.

Safety

A controller asked to reach a nearly uncontrollable direction commands very large forces. On a real rig this means the motor runs at its current limit and the cart slams into the end stops. Always set a force or current limit in the driver, keep the emergency stop within reach, and try new designs in the simulator first (safety, BR-08).

Worked example

Task. For the cart of MA301 F0-67 (A = [[0, 1], [0, −0.4]], B = [0, 0.5]ᵀ, from F9-59's worked example): (a) is it controllable? (b) is it observable with a speed sensor only? (c) with a position sensor only?

  1. AB = [[0, 1], [0, −0.4]]·[0, 0.5]ᵀ = [0.5, −0.2]ᵀ. So Wc = [B, AB] = [[0, 0.5], [0.5, −0.2]], with determinant 0·(−0.2) − 0.5·0.5 = −0.25 ≠ 0. Rank 2: controllable. The force reaches the speed directly and the position through the speed.
  2. Speed sensor C = [0, 1]: CA = [0, −0.4]. Wo = [[0, 1], [0, −0.4]] has a zero first column: rank 1. The position never affects anything the speedometer sees. Not observable; and since the unobservable mode (position, eigenvalue 0) does not decay, not detectable either.
  3. Position sensor C = [1, 0]: CA = [0, 1]. Wo = I, rank 2: observable. Speed shows up as the change of position.

Part (b) is a common real mistake: a motor with only a speed sensor cannot hold a position, however it is tuned. Number check, run R3 — real output of checks.cpp:

Where the analogy breaks


    

  • Nadia with her eyes closed could still count pedal turns and estimate how far she has gone. Our angle-only cart-pole has no such extra sense: observability is strictly about the sensors in C, nothing else.
    • 

  • Tomás holding two bicycles could let go of one, or push one with his knee: people improvise new actuators. A controller cannot; uncontrollability is fixed by the hardware until someone adds an actuator.
    • 

  • For the bicycles, "harder" means tiring. For a motor, a direction needing ten times the limit is not tiring but impossible, and the rank test does not warn you (Figure 3).

Method hints


The minimum-energy input is the cheapest possible input for a linear model: if it exceeds the limit, no controller can do better. Write each expensive goal as a sum of a "same lean" part and an "opposite lean" part.

Summary


    

  • Controllable: the inputs can reach every state; test rank [B, AB, …, An−1B] = n.
    • 

  • Observable: the outputs determine every state; test rank [C; CA; …; CAn−1] = n; dual to controllability.
    • 

  • The PBH test checks each eigenvalue and names the mode that fails.
    • 

  • The cart-pole is controllable with one force and observable from the cart position alone or with the angle; with the angle alone, the cart position is invisible.
    • 

  • Two identical poles on one cart have an uncontrollable, unstable difference mode: no controller can balance them.
    • 

  • "How controllable" matters more than "whether": Gramians and minimum-energy inputs show directions that need impossible forces.
